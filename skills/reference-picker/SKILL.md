# 콘텐츠 기획자 — reference-picker

## 하는 일
영상 목록에서 떡상 기준(조회수÷구독자), 최근 며칠, 최소 길이를 지킨 영상 중 내 주제 키워드가 제목에 있는 것만 남기고 한 채널에서 몰리지 않게 골라 제목 특징(숫자·질문 등)을 붙여 보드로 만든다.
결과는 AI가 느낌으로 매기는 것이 아니라 스크립트가 표(규칙)대로 세고 판정한다. 기준을 바꾸고 싶으면 스크립트가 아니라 규칙 표를 고친다.

## 필요한 것
- 필요한 프로그램: Python 3 (없으면 멈추고 무엇이 없는지 한 줄로 알린다)
- 키·로그인: 없음. 이 스킬은 아무 서비스에도 접속하지 않고 파일만 읽고 쓴다.

## 작업 폴더
- 작업 폴더는 지금 작업 폴더 안의 `기획후보-보드` 로 한다. 처음 실행하면 연습 자료와 규칙 표가 그 안에 한 번만 복사된다. 이미 있는 파일은 덮어쓰지 않는다.
- 스킬 폴더의 `samples` 는 원본이다. 고치지 않는다. 사용자가 고치는 것은 작업 폴더의 복사본이다.

## 순서
1. 먼저 한 가지를 묻는다: "연습 자료로 먼저 한 번 볼까요, 바로 내 자료로 할까요?" 연습 결과를 사용자의 실제 결과처럼 말하지 않는다.
2. 내 자료로 할 때: 영상 목록은 표(CSV)로 `01_레퍼런스` 에 둔다. 칸: 제목, 채널, 조회수, 구독자수, 올린 날짜, 길이, 모은 날짜, 주소. 목록은 사용자가 유튜브에서 직접 모아 주거나, 사용자가 허락하면 Aside 로 화면에서 읽기만 해서 표로 옮긴다. 다른 파일은 `--file 이름.csv`.
   내 자료의 칸 이름이 다르면 사용자에게 어느 칸이 무엇인지 한 번 확인하고, 원본은 고치지 않고 칸 이름을 맞춘 사본을 쓴다.
3. 규칙 표를 내 것으로 바꾼다. 무엇으로 바꿀지 모르면 사용자에게 묻는다(지어내지 않는다).
   - `02_규칙/내주제.csv` (키워드, 이유): 내 가게·채널이 다루는 주제 말
   - `02_규칙/고르는기준.csv` (기준, 값, 뜻): 떡상 기준(배), 최근 며칠 안, 가장 짧은 길이(분), 한 채널 최대
   - `02_규칙/제목특징.csv` (특징, 찾는 말, 왜 눌러보나): 제목에서 찾을 특징
4. 이 스킬 폴더의 `scripts/run.py` 를 Python 으로 실행한다. 작업 폴더는 `--work <작업 폴더 경로>` 로 넘긴다. 이 줄은 AI용이다. 사용자에게 명령어를 보여 주지 않는다.
5. 결과를 열어 본다. 만들어지는 것: 결과/기획후보보드.html, 결과/기획후보보드.csv. HTML 화면은 허브 오른쪽 미리보기에 띄운다.
6. 스크립트가 알려 주는 확인 3가지를 읽고 그대로 전한다.
   - 오래된 영상이 없나
   - 내 주제와 맞나
   - 한 채널에 몰리지 않았나
   "확인 필요"가 있으면 이유를 쉬운 말로 알리고, 규칙 표를 어떻게 고치면 되는지 제안한 뒤 다시 돌린다. 표를 고치기 전에 사용자에게 먼저 묻는다.
7. 사람 눈으로 한 번 더 볼 것을 사용자에게 알린다(`references/검수표.md` 참고).
   - 후보 영상을 직접 열어 조회수·날짜가 표와 맞나

## 지킬 것
- 조회수·구독자 숫자는 사용자가 준 표 그대로 쓰고 지어내지 않는다. 남의 영상 내용을 그대로 베끼는 기획은 만들지 않고 "무엇이 눌러보게 했는지"만 가져온다.
- 스크립트 코드는 고치지 않는다. 결과가 이상하면 규칙 표나 입력 자료를 본다.
- 사용자에게 보이는 안내와 만든 화면·문서에 터미널 명령어와 내 컴퓨터 폴더 경로를 넣지 않는다.
- 키·비밀번호·토큰을 묻거나 저장하지 않는다.

## 하지 않는 것
- 유튜브 API 로 영상을 자동으로 모으는 기능은 이 스킬에 넣지 않았다(별도 키가 필요).

## 다 하면
결과 화면을 연 뒤 한 줄로 알린다: "OO를 만들었어요. 확인 3가지 중 N가지 통과, 확인 필요 M개." 그리고 질문 하나: "규칙 표에서 바꾸고 싶은 기준이 있나요?"
