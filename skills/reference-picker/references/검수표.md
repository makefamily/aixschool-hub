# 콘텐츠 기획자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 오래된 영상이 없나 | 오래전 유행은 지금 따라 해도 안 먹힙니다 | `고르는기준.csv` 의 최근 며칠 안을 확인합니다 |
| 내 주제와 맞나 | 주제가 다르면 잘된 이유를 가져와도 못 씁니다 | `내주제.csv` 에 내 주제 말을 한 줄 더합니다 |
| 한 채널에 몰리지 않았나 | 한 사람 스타일만 따라가게 됩니다 | `고르는기준.csv` 의 한 채널 최대를 확인합니다 |

**사람 눈으로 한 번 더**

- [ ] 보드 1위 영상을 실제로 열어 봤나 (썸네일·첫 10초)
- [ ] 공통점 중 내 다음 영상 제목에 써볼 것을 하나 골랐나
- [ ] 확인 필요가 0개인가
