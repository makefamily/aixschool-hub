# 출처와 라이선스

이 폴더의 `SKILL.md`와 `references/`는 HeyGen의 HyperFrames 공식 에이전트 스킬(hyperframes, hyperframes-core, hyperframes-cli, hyperframes-audio)을 허브 학생용으로 줄이고 고친 것이다.

- 원본: https://github.com/heygen-com/hyperframes (스킬 설치기 `npx skills add heygen-com/hyperframes`로 받는 것과 같은 계열)
- 라이선스: Apache License 2.0. 전문은 같은 폴더의 `LICENSE`. 확인일 2026-11-18.
- 변경 내용: 한국어 안내 추가, 글꼴·스킬 자동 설치·키 빈칸 원칙 반영, 플러그인·클라우드·계정 관련 절차와 큰 자산(프레임 프리셋, 글꼴 파일, 레지스트리 예시)을 뺐다. 영문 본문은 원본 그대로 두었고, 허브 규칙과 충돌하는 곳에는 `SKILL.md` 앞부분이 우선한다.
- 같이 쓰는 GSAP는 별도 라이선스(Webflow 표준 무료 라이선스, 상업 사용 가능): https://gsap.com/standard-license
- 확인된 범위: `SKILL.md` 본문, `references/` 중 types·film·format·motion·sound·look·overlays·captions·review·runtimes·spec·story·storyboard 계열은 위 공개 저장소의 `skills/hyperframes/`와 같은 파일이다.
- `references/core/`, `references/cli/`의 일부, `references/sound-skill.md`, 그리고 `../motion-graphics`, `../general-video`, `../faceless-explainer`는 HyperFrames CLI(npm 패키지 `hyperframes`, Apache-2.0, 저장소 heygen-com/hyperframes)가 배포하는 같은 계열 스킬이다. 같은 이름의 안내서가 저장소 `docs/guides/`에 있다. 확인일 2026-11-18.
- `../awwwards-animations`는 별도 참고 스킬이다(그 폴더 README에 MIT 표기).
