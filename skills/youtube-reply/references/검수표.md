# 답글 게시 전 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 미리보기 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 답글에 못 채운 빈칸({이름} 같은)이 남지 않았나 | "{이름}님 감사합니다"가 그대로 나가면 로봇 티가 납니다 | `답글규칙.csv` 의 빈칸 이름을 `{이름}` 으로 맞춥니다 |
| 광고·연락처 댓글에는 답하지 않았나 | 광고 댓글에 답하면 그 광고를 내 채널이 밀어주는 꼴이 됩니다 | `제외단어.csv` 에 그 광고에 들어간 말을 한 줄 더합니다 |
| 같은 사람에게 두 번 답하지 않았나 | 같은 사람이 댓글을 여러 번 달아도 답은 한 번이면 됩니다 | 프로그램이 알아서 막습니다. 걸리면 AI가 원인을 확인합니다 |

**사람 눈으로 한 번 더**

- [ ] 답글 링크가 내가 주려던 자료 주소가 맞나
- [ ] 답글 말투가 내 채널 말투와 맞나
- [ ] 확인 필요가 0개인가 — 0개가 아니면 게시하지 않습니다

> 유튜브는 링크가 들어간 답글을 "검토 대기"로 잠시 숨길 때가 있습니다. 게시 뒤 유튜브 스튜디오 > 댓글에서 한 번 확인하세요.
