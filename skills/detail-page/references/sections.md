# 섹션 설계 & 카피 규칙

## 1. 뼈대는 "랜딩페이지 7단계"

상세페이지는 예쁜 이미지 모음이 아니라 **순서가 있는 설득**이다.
가이드북형 랜딩 7단계를 상세페이지 섹션으로 그대로 매핑한다.

| 랜딩 7단계 | 상세페이지 섹션 | 역할 |
|---|---|---|
| ① 도입부 | HERO | 3초 안에 "이게 뭐고 얼마인가" |
| ② 공감대 | 문제 제기 (.pains) | 고객 말투로 증상 3개 |
| ③ 신뢰도 | 데이터/실적 (.grid3, .metabar) | 숫자로 자격 증명 |
| ④ 문제 제기 | 다크 선언 (.state) | "다른 자료로는 왜 안 됐나" |
| ⑤ 해결방안 | 커리큘럼(.parts) · 전용 무기(.vault) · 비교표(.cmp) | 내용물 전개 |
| ⑥ 반박 제거 | 적합/부적합(.fitgrid) · 보증(.guar) · FAQ | 구매 저항 해체 |
| ⑦ CTA | 최종 CTA (.cta) | 가격 재확인 + 행동 |

보너스(.bonus)·희소성(.rise)은 ⑤와 ⑦ 사이에 끼워 밀도를 올린다.

## 2. 무료 리드마그넷 vs 유료 상품

| | 무료판 (detail_v2.html) | 유료판 (detail_premium.html) |
|---|---|---|
| 섹션 수 | 7개, 짧게 | 13개, 길게 |
| 가격 표기 | `29,000원 → 0원` (상당가 앵커링) | `59,000 → 33,000` + 인상 예고 밴드 |
| 핵심 목적 | 이메일/DB 확보 | 결제 |
| 필수 | "진짜 0원인가요" FAQ | 비교표 · 적합/부적합 · 보증 · 환불 기대치 |
| 톤 | 가볍게, 부담 제거 | 근거·전용성·희소성 |

무료가 이미 있으면 유료 상세페이지엔 **비교표(.cmp)가 사실상 필수**다.
"무료 봤는데 왜 또 사?"가 최대 반박이고, 표 하나가 그걸 해결한다.

## 3. 카피 규칙 (de-slop)

- **이모지 금지.** 섹션 배지 1~2개(🔥🔒) 외 본문엔 넣지 않는다. AI티의 8할이 이모지다.
- **구어체.** "~하실 수 있습니다" 대신 "~하면 됩니다 / ~돼요". 내 평소 말투 그대로.
- **방어 가능한 숫자만.** 과장된 배수 대신 실측치. 표시광고 리스크 + 신뢰.
  - 상세페이지에 "판매량 늘면 인상"이라 썼으면 **실제로 그렇게 운영해야 한다.**
- **h1/h2는 2줄, 뒷줄에 `.hl` 하이라이트.** 한 줄짜리 긴 제목은 임팩트가 죽는다.
- **`word-break:keep-all`** — 한글 단어가 중간에서 안 잘린다. body에 이미 들어있음.
- **문제 제기는 고객이 실제로 쓰는 문장으로.** "조회수가 늘 세 자리에서 안 넘어간다"처럼.
- **부적합 목록을 진짜로 쓴다.** "이런 분껜 비추천"에 진짜 비추천을 적으면 신뢰가 올라가고
  환불·클레임이 준다. 형식적으로 쓰면 역효과.

## 4. 시각 리듬

밝은 섹션만 이어지면 스크롤이 지루하다. **다크 섹션을 3~4개 간격으로 꽂는다.**

```
HERO(다크) → rise(연블루) → pain(흰) → data(흰) → state(다크) →
cmp(흰) → parts(흰) → vault(딥네이비) → fit(흰) → bonus(연블루) →
guar(다크) → faq(흰) → CTA(액센트 풀블리드)
```

- 폰트 스케일은 1080px 기준: h1 104 / h2 66 / 리드 30 / 본문 25~27 / 캡션 22.
  **모바일에서 이미지가 축소돼 보이므로 웹 감각보다 1.5~2배 크게 잡는다.**
- 섹션 패딩 110/90 고정. 흔들면 리듬이 깨진다.
