# 숏폼 영상편집자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 숏폼 길이가 정해둔 범위 안인가 | 너무 길면 끝까지 안 보고, 너무 짧으면 이야기가 안 끝납니다 | `숏폼길이.csv` 의 가장 짧게·가장 길게를 확인합니다 |
| 후보끼리 겹치지 않나 | 같은 장면이 두 번 나가면 손님이 지루해합니다 | 프로그램이 겹치는 후보를 뺍니다. 걸리면 AI가 원인을 확인합니다 |
| 첫 3초 안에 훅 말이 있나 | 첫 3초에 넘기면 뒤는 안 봅니다 | `훅말.csv` 에 내 손님이 멈추는 말을 더합니다 |

- [ ] 앞뒤 맥락 없이 봐도 뜻이 통하나
