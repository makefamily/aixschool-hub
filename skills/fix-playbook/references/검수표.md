# IT 운영 담당자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 모든 신고에 조치나 담당이 정해졌나 | 담당이 없는 신고는 아무도 안 봅니다 | `조치표.csv` 의 조치·담당 칸을 채웁니다. 표에 없는 증상은 새 증상 목록으로 갑니다 |
| 위험한 조치에 사람 확인 표시가 붙었나 | 보내는 작업을 다시 돌리면 같은 문자가 두 번 나갈 수 있습니다 | 위험한 조치를 뒤 칸으로 옮기고 `위험조치.csv` 에 그 말을 적습니다 |
| 같은 증상을 한 번에 묶었나 | 같은 문제를 세 번 따로 고치면 시간도 세 배입니다 | `조치표.csv` 에 같은 문제 이름이 다른 조치로 두 번 적혀 있는지 봅니다 |

**사람 눈으로 한 번 더**

- [ ] 먼저 해볼 조치가 우리 회사에서 실제로 할 수 있는 일인가
- [ ] 사람 확인이 붙은 조치는 누가 확인할지 정했나
- [ ] 새 증상을 조치표에 한 줄씩 더했나
