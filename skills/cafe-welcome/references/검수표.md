# 네이버 카페 관리자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 하루 최대 개수를 지켰나 | 한꺼번에 많이 달면 도배로 보입니다 | `하루최대.csv` 를 확인합니다. 넘친 글은 다음 날로 넘어갑니다 |
| 같은 문장이 연달아 나오지 않나 | 같은 인사가 줄줄이 달리면 사람이 단 댓글처럼 안 보입니다 | `환영문장.csv` 에서 그 단어 문장을 하나 더 적습니다 |
| 광고 글에는 달지 않았나 | 광고 글에 환영 인사를 하면 광고를 인정해 준 것처럼 보입니다 | `댓글안다는말.csv` 에 그 광고 말을 한 줄 더합니다 |

**사람 눈으로 한 번 더**

- [ ] 내 카페 말투와 맞나
- [ ] 닉네임 자리가 어색하지 않나
- [ ] 확인 필요가 0개인가
