# Aside로 네이버 편집기 조작 (AI용)

학생에게 보여주지 않는다. 2026-11-18 이 맥의 Aside에서 실제로 읽고 입력해 본 구조다. 네이버 화면은 바뀔 수 있으니 안 맞으면 화면을 다시 읽고 고친다.

## 확인된 것 (실측)
- 글쓰기 주소를 열면 내 블로그의 글쓰기 주소로 이동하고, 편집기는 바깥 페이지 안의 틀(iframe, 주소에 PostWriteForm 포함) 안에 있다. 조작은 그 틀을 찾아서 한다.
- 제목 칸 `.se-section-documentTitle`. 눌러서 키보드 입력하면 들어간다.
- 본문 `.se-section-text`. 첫 본문을 눌러 키보드 입력하면 들어간다. Enter로 문단이 나뉜다.
- 굵게 `.se-bold-toolbar-button`: 켜고 입력하고 끄면 `<b>`로 들어간다(확인).
- 글자 크기 `.se-font-size-code-toolbar-button`: 크기 11, 13, 15(기본), 16, 19, 24, 28, 30, 34, 38. 각 항목 클래스에 `font-size-code-fs24`처럼 크기가 들어 있다.
- 인용구 `.se-toolbar-item-insert-quotation .se-document-toolbar-select-option-button`: 스타일 default, line, bubble, underline, postit, corner. 항목 클래스 `se-toolbar-option-insert-quotation-quotation_line-button` 형식.
- 구분선 `.se-toolbar-item-insert-horizontal-line`, 사진 `.se-toolbar-item-image`가 도구 모음에 있다(눌러 보지는 않음).
- 임시저장 글 개수는 `[aria-label*="임시저장"]`의 라벨("임시저장된 글 보기, N개")에서 읽는다. 저장 전후 비교에 쓴다(예리 publisher.py 293~370줄과 같은 방식).
- 저장 단추는 머리말의 "저장", 발행은 "발행". 발행은 누르지 않는다.
- 팝업 "작성 중인 글이 있습니다. … 이어서 작성하시겠습니까? 취소 / 확인": 앞서 입력하다 닫은 내용이 자동으로 남아 있을 때 뜬다. 입력이 시작된 뒤에도 늦게 뜰 수 있다. 취소를 누르면 사라지고 다시 열어도 안 뜬다(확인). 선택자 `.se-popup-alert-confirm`, 취소 `.se-popup-button-cancel`(예리 editor.py 119~245줄과 같다).

## 입력 요령
- 입력 직전 팝업을 확인한다(popup 텍스트가 있으면 취소).
- 입력은 키보드 입력 API로 한 문단씩. 제목, 본문 순으로 입력하고 매번 칸의 글자를 읽어 확인한다.
- 소제목(미시험): 글자 크기 단추 → 24 항목 → 굵게 켜기 → 입력 → Enter → 크기 15와 굵게 끄기. 안 되면 입력 후 그 줄을 선택(Shift+Home)해 같은 단추를 누른다.
- 인용구(미시험): 인용구 단추 → 스타일 항목 → 입력 → ↓ ↓ Enter로 빠져나오기(예리 editor.py 1139~1190줄).
- 사진(미시험): 사진 단추를 누르고 파일 선택 창을 파일 선택 기능으로 받아 파일을 지정한다(예리 editor.py 1624~1700줄은 숨은 파일 입력 칸에 경로를 넣는다). 안 되면 파일 입력 칸에 직접 지정, 그것도 안 되면 학생이 끼워 넣도록 안내.
- 실행은 한 번 120초, 끝나면 탭이 닫힌다. 스크린샷은 실행 안에서 내용을 출력해 밖에서 파일로 저장한다.

## 시험할 때
시험 문구만 넣고 저장하지 않는다. 끝나면 본문과 제목을 모두 지우고(전체 선택 후 삭제), 임시저장 글 개수가 시작할 때와 같은지, 다시 열었을 때 "작성 중인 글" 팝업이 없는지 확인한 뒤 탭을 닫는다. 팝업이 있으면 취소를 눌러 지운다.
