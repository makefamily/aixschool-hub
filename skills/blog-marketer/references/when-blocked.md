# 막혔을 때 (AI용)

원칙: 막히면 멈추고 사실대로 알린다. 우회하지 않는다.

| 증상 | 하는 일 |
|---|---|
| 로그인 창에서 보안 확인·추가 인증 | 학생이 직접 푼다. 도구는 기다리기만 한다(기본 5분). 시간이 지나면 같은 창에서 이어 하도록 다시 실행한다 |
| 자동 입력 환경을 네이버가 막아 로그인이 안 됨 | 더 시도하지 않는다. 글 파일을 그대로 보여주고 "복사해서 네이버 글쓰기에 붙여 넣는 방식"으로 안내한다. 사진은 폴더 위치를 알려 준다 |
| 글쓰기 화면을 못 찾음 | 블로그가 아직 없는지(네이버 블로그 개설 필요), 화면이 바뀌었는지 캡처로 알린다. 학생이 블로그를 만들게 안내하고 다시 시도 |
| 사진이 안 들어감 | 그 자리는 `[사진 자리: ...]` 글자로 남고 도구가 알려 준다. 작성창에서 끼워 넣도록 안내 |
| 저장 확인 실패(`save_confirmed` false) | 캡처를 보여주고 임시저장 목록을 직접 열어 보게 한다. 저장됐다고 말하지 않는다 |
| Aside가 없거나 로그인 안 됨 | `aside-browser`의 설치 안내를 한 번 하고, 하지 않겠다면 Playwright 대안으로 간다 |
| Aside에서 네이버가 로그인 화면으로 보냄 | 학생이 Aside 창에서 직접 로그인. 보안 확인도 학생이 푼다 |
| 입력 중 "작성 중인 글이 있습니다" 팝업 | 취소(새 글)를 누르고 제목부터 다시 확인한다. 이어쓰기(확인)는 누르지 않는다 |
| 소제목 크기·인용구·구분선이 안 적용됨 | 그 서식만 포기하고 일반 글로 둔 채 계속한다. 무엇을 못 했는지 마지막에 알린다 |
| Aside 입력이 두 번 실패 | 완성된 글을 복사해서 붙여 넣는 방식으로 바꾼다 |
| 같은 프로필 창이 이미 열려 있음 | 열린 창을 닫아 달라고 한다 |

네이버 화면 구조는 바뀔 수 있다. Aside 경로는 `references/aside-editor.md`의 선택자를 현재 화면에 맞게 고친다. 도구가 못 찾는 부분이 생기면 이 스킬의 `scripts/naver_draft.py` 안 선택자(.se-section-documentTitle 등)를 현재 화면에 맞게 고치고, 고친 걸 학생에게 한 줄로 알린다.
