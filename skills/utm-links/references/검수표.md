# 퍼포먼스 마케터 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 채널 표기가 표와 같나 | 같은 채널을 instagram, Instagram 처럼 다르게 적으면 성적표가 두 줄로 쪼개집니다 | `채널표기.csv` 를 영어 소문자로 고칩니다 |
| 링크에 한글·띄어쓰기가 그대로 들어가지 않았나 | 한글·띄어쓰기가 든 링크는 주소가 깨져 보이고 잘립니다 | `캠페인이름.csv` 의 영어로 짧게 칸을 채웁니다 |
| 같은 캠페인 이름이 다른 뜻으로 겹치지 않나 | 다른 행사가 같은 이름을 쓰면 매출이 섞여서 어느 행사 덕인지 모릅니다 | `캠페인이름.csv` 의 시작일이나 영어 이름을 다르게 합니다 |

**사람 눈으로 한 번 더**

- [ ] 내가 실제로 링크를 올리는 곳이 채널표기.csv 에 다 있나
- [ ] 만든 링크를 눌러보면 원래 페이지가 잘 열리나
