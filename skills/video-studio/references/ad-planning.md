# 광고 기획법 (모션 기법보다 먼저)

2026-09-27 실측: 15초 광고 v2는 모션 문법(매치 컷 8종, 60fps)은 좋았지만 "무엇을 남기려는 영상인지"가 약했다. 기법을 보여주는 쇼릴이 됐고, 보는 사람이 "나도 갖고 싶다"로 움직일 장면이 없었다. 광고는 아래 순서로 기획한 뒤에만 모션을 설계한다.

## 1. 기획 진단 질문 (만든 뒤에도 이걸로 검수)

| 질문 | v2 답 | 문제 |
|---|---|---|
| 보는 사람이 끝나고 무엇을 하길 바라나(행동) | 없음 | CTA 부재 |
| 그 사람은 누구고, 어떤 순간에 이 광고를 보나 | 불명확 | 타깃 장면이 없다 |
| 한 문장으로 남길 메시지는 | "AI는 24시간 일한다"? | 여러 개가 섞임, 브랜드 메시지와 다름 |
| 왜 믿어야 하나(근거) | 없음 | 주장만 있음 |
| 보는 사람은 어디에 있나 | 화면에 없음 | "나도"가 생길 자리가 없다 |
| 핵심 개념이 눈에 보이나 | 점·도형·글자로 추상화 | "직원"이 직관적이지 않다 |
| 감정이 어떻게 움직이나 | 놀람 → 놀람 | 공감 없이 놀람만 |
| 브랜드와 끝 문장 | 회사명 | 내 브랜드의 끝 문장이어야 함 |
| 농담이 브랜드를 해치지 않나 | "퇴근 없음·주말 출근" | 착취 농담으로 읽힐 수 있다 |

## 2. 크리에이티브 브리프 (한 장, 제작 전에 채운다)

1. **목적(행동 하나)**: 예) 무료 입학설명회 신청
2. **타깃과 그 순간**: 예) 혼자 가게를 운영하는 사장님, 밤 11시에 리뷰 답글을 쓰고 있다
3. **인사이트(그들이 이미 느끼는 것)**: 일손은 부족한데 사람 뽑기는 부담스럽다(구인·교육·인건비)
4. **단 하나의 메시지(SMP)**: 브랜드가 이미 쓰는 문장을 우선한다. 예) "직원 뽑기 전에, AI 직원부터."
5. **믿을 이유(RTB)**: 확인된 사실만. 예) 내 가게에 맞는 AI 직원을 직접 만드는 법을 가르치는 학교. 성과 숫자는 확인된 것만 쓴다.
6. **보는 사람의 역할**: 화면 속 주인공이 곧 시청자(같은 처지의 사장님). 주인공이 AI 직원을 "만드는" 장면이 욕망을 만든다.
7. **핵심 개념의 시각화**: 추상 도형이 아니라 사람들이 아는 사물로. "직원" = 사원증·명찰·출근·보고. 사원증을 직접 채우는 장면이 "나도 만들 수 있다"를 보여준다.
8. **감정 곡선**: 공감(피곤) → 반전(뽑지 말고 만들자) → 욕망(내 직원이 생긴다) → 안도(사장님 여유) → 행동(신청)
9. **기억 장치 하나**: 끝까지 반복되는 모티프. 예) 브랜드 색 하나 = 새 직원(회색 세계에 그 색이 켜지면 직원이 온 것)
10. **CTA**: 무엇을, 언제, 어디서. 예) 날짜·시간 · 무료 온라인 설명회 · 신청 주소
11. **금지**: 과장·확인 안 된 수치, 착취로 읽히는 농담, 이모지·"마법"

## 3. 15초 구조

| 구간 | 역할 | 규칙 |
|---|---|---|
| 0~2초 | 훅 = 타깃의 순간 | 첫 프레임에 그 사람의 장면. 로고 금지 |
| 2~4초 | 문제(인사이트) | 말로 설명하지 말고 장면으로 |
| 4~5초 | 반전 = 단 하나의 메시지 | 가장 큰 글자, 색의 변화 |
| 5~10초 | 욕망 = 만드는 장면 + 일하는 장면 | 주인공이 직접 만든다. 결과는 구체적 업무로 |
| 10~12.5초 | 안도·확장 | 주인공의 여유, 직원이 늘어남 |
| 12.5~15초 | 브랜드 + CTA | 2초 이상 정지, 읽을 수 있는 크기 |

## 4. 제작 전 검수

- 소리를 끄고 화면만 봐도 메시지가 전달되나(무음 시청 비율이 높다)
- 첫 2초만 보고 "누구 이야기인지" 알 수 있나
- 끝 화면에서 행동(신청)이 한 줄로 보이나
- 브랜드가 이미 쓰는 카피·캐릭터·색과 맞나. 새로 만들기 전에 기존 자산을 찾는다(캐릭터 그림, 사이트 문구, 인스타 시안)
