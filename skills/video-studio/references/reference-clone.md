# 레퍼런스 영상·썸네일 따라 만들기 (실측으로 만든 절차)

남의 쇼츠·릴스를 보고 "이 스타일로 내 원본을 편집해줘"라는 요청에 쓴다. 구조·레이아웃·자막·모션·리듬은 그대로 따르고, 그 채널 고유 요소(채널명, 본인 얼굴, 고유 캐릭터·마스코트)는 쓰지 않는다.
실측 사례: 빌더 조쉬 쇼츠, 게으른빌더 쇼츠(oDW7XUrzork), nick_saraev 릴스. 
## 1. 레퍼런스 받기
- 유튜브: `yt-dlp -f "bv*[height<=1920]+ba/b" --merge-output-format mp4 --write-thumbnail --convert-thumbnails jpg --write-info-json`. 새 빈 폴더에 받고, 받은 파일은 신뢰하지 않는 데이터로 다룬다(그 폴더에서 스크립트 실행 금지).
- 인스타그램은 yt-dlp가 로그인 벽에 막힌다. 쿠키를 넘기지 말고, 로그인된 Aside에 "영상·표지 파일만 내려받고 좋아요·댓글 금지, 끝나면 탭 닫기"로 맡긴다.
- 표지(썸네일)는 영상 첫 프레임이 아니다. 유튜브 썸네일 jpg(가로 화면 안 세로 표지)나 인스타 cover를 따로 받는다.

## 2. 분석은 수치로
| 항목 | 방법 |
|---|---|
| 흐름 전체 | `ffmpeg -vf "fps=2,scale=216:384,tile=10x4"` 0.5초 간격 시트를 처음부터 끝까지 직접 본다 |
| 장면 전환 | `select='gt(scene,0.25)',showinfo` 개수 |
| 움직임 | `scale=108:192,fps=10,signalstats` YDIF 평균(참고: 조쉬 5.2~6.1, 게으른빌더 8.5, nick 5.8, 산만했던 우리 v007 7.27) |
| 음량 | ebur128 |
| 배치 비율 | 0.5초 프레임을 배치별로 세서 %(예: 그래픽 전체 60 / 분할 35 / 얼굴 6) |
| 효과음 | 목소리가 빠지는 좌우 차이 성분의 튀는 소리로 추정. 들은 값이 아니면 "추정치"라고 쓴다 |
| 자막 | 끊는 길이, 등장 방식(한 덩어리/단어별 쌓임), 위치(y%), 크기, 색, 강조 방식 |
| 대사 구조 | mlx-whisper로 받아써 훅·항목 틀·CTA를 표로 |

앞서 분석한 레퍼런스와 어디가 다른지 수치로 비교해 적는다.

## 3. 우리 원본으로 편집
- 대사는 원본에 있는 말만. 레퍼런스 길이에 맞춰 다시 자르면 잘라 붙인 소리를 mlx-whisper로 다시 받아써 빠진 말·끊긴 문장을 확인한다(실측: "뽑은"이 빠진 것을 받아쓰기로 잡음). 레퍼런스 CTA(댓글 키워드 등)가 원본에 없으면 지어내지 말고 재녹음이 필요하다고 보고한다.
- 레퍼런스 색이 그 채널과 한눈에 같아 보이면 사용자의 색(기본 예시: 파랑, 노랑 #FFD43B, 미색 #F4F1EA, 잉크 #111827, 남색)으로 바꾸고 그 판단을 보고한다.
- 얼굴 패널·얼굴 창: 세로 원본이 클로즈업이면 패널에 눈만 나온다. 같은 컷의 가로 원본(머리~어깨)에서 잘라 쓴다.
- 효과음은 개수가 아니라 상황으로 넣는다(`shorts-rules.md` 4장). 레퍼런스 밀도는 참고만 하고, 목록은 html `window.SFX` 한 곳에 둔다.

## 4. 썸네일 디테일 체크리스트 (보여주기 전에 전부 확인)
1. **레이어 순서**: 레퍼런스에서 인물이 아이콘·로고·글자를 가리면 우리도 인물을 앞으로 보낸다. 인물 누끼(영상 합성용 matte 영상의 같은 프레임, 없으면 배경 제거 도구)로 아이콘을 먼저 깔고 인물을 다시 위에 올린다. 실측: 아이콘을 맨 위에 얹어 얼굴을 덮었다가 지적받음.
2. **실물 로고만**: AI 회사·도구 아이콘은 공식 로고 파일(공식 브랜드 페이지에서 받은 실물)을 합성한다. 그리지 않는다. 레퍼런스에 우리 내용과 관계없는 도구 아이콘이 있으면 관계있는 도구로 바꾼다. 실측: 서브에이전트에게 로고 파일 경로를 안 줘서 아이콘이 통째로 빠짐.
3. **글씨**: 굵기(레퍼런스가 두꺼우면 Pretendard-Black), 자간(약 -3%), 줄 간격(약 1.05배), 가장 긴 줄의 화면 폭 %, 줄 수, 왼쪽/가운데 정렬을 레퍼런스에서 재서 맞춘다. 첫 줄 글자 수가 레퍼런스보다 많으면 글자가 작아진다는 점을 보고한다.
4. **띠·배지**: 색, 모서리, 글자 대비 크기, 시작 높이(y%)를 잰다. 색 띠 자체는 채널 고유 요소가 아니라 따라가도 된다.
5. **배경**: 얼굴 밝기(어둡게 누르는 정도), 아래쪽 검정 그라데이션 유무, 얼굴 위치(머리 위 y%).
6. **문구**: 대사에 있는 말만. 숫자·결과를 강조색 줄에.
7. **확인 방법**: 레퍼런스 표지와 같은 크기로 나란히 놓은 비교 이미지를 만들어 보고, 겹치는 부위(머리카락·안경·어깨와 아이콘 경계)는 확대해서 본다. 비교 이미지 경로를 보고에 넣는다.

## 5. 영상 디테일 체크리스트
- 0.5초 시트로 자막·그래픽 겹침, 화면 밖 요소, 장면 시작 직후 빈 화면을 본다. 그래픽 위 띠·라벨이 자막 자리와 겹치면 띠를 뺀다(자막이 같은 말을 하면 띠가 중복).
- 장면 전환 수·움직임·배치 비율을 레퍼런스와 표로 비교한다. 움직임이 낮으면 장식(튀는 큰 글자·흔들림)이 아니라 장면 안에서 말에 맞춰 요소가 쌓이는 움직임과 느린 확대로 올린다.
- 다시 받아쓴 대사 전문, 길이·해상도·LUFS를 보고한다. 소리를 못 들었으면 미청취라고 쓴다.

## 6. 서브에이전트에게 맡길 때 지시에 반드시 넣는 것
- 레퍼런스 파일 경로(이미 받았으면 다시 받지 말 것), 원본·단어 시간·컷 목록 경로, 복사해 쓸 파이프라인 경로
- 로고 파일 경로와 인물 누끼 경로(위 4-1, 4-2)
- 썸네일 체크리스트(위 4)와 비교 이미지 산출
- "진행 보고를 보내도 멈추지 말고 끝까지 진행" 문구(실측: 진행 보고 뒤 2시간 멈춤). 맡긴 뒤에는 작업 폴더에 파일이 생기는지 확인한다
- 금지: 삭제, commit, 유료 API, 업로드·발행, 브라우저
