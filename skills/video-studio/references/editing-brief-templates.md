# AI 자동편집 지시문 템플릿

내 영상의 조건을 대괄호 안에 채운 뒤 AI 편집 도구에 붙여 넣으세요. 아래 수치와 스타일은 편집을 시작하기 위한 예시입니다. 플랫폼 공통 규정이나 공식 권장값을 뜻하지 않습니다.

## 1. 먼저 확인할 입력

- 원본 파일: [파일명 또는 도구에서 접근 가능한 경로]
- 원본 정보: [가로·세로 크기 / 프레임레이트 / 전체 길이 / 자막·전사 유무]
- 결과물 용도: [유튜브 설명 영상 / 강의 다시보기 / 세로 쇼츠]
- 보는 사람과 시청 후 행동: [누가 보고 무엇을 이해하거나 하게 될지]
- 반드시 살릴 내용: [핵심 주장 / 시연 / 사례 / 결론]
- 빼도 되는 내용: [기술 점검 / 같은 말을 반복한 구간 / 실제 편집 범위]
- 참고 영상: [접근 가능한 링크 또는 첨부 영상과 참고할 구간]
- 결과 길이: [목표 범위]. 핵심 내용이 잘리면 길이보다 의미 보존을 우선한다.
- 전달 형식: [완성 영상 / 자막 파일 / 편집 프로젝트 / 편집 결정 목록]

원본 정보를 모르면 추측해서 채우지 말고, 먼저 AI에게 파일의 메타데이터와 접근 가능 여부를 확인하게 하세요.

## 2. 공통 지시문

```text
첨부한 원본을 아래 조건에 맞춰 편집해줘.

[목적]
대상: [시청자]
영상 목적: [한 문장]
완성 길이: [범위]
출력 화면: [가로/세로, 화면 비율, 해상도]
반드시 보존할 내용: [목록]

[실행 가능 여부]
원본의 실제 영상·소리·전사에 접근할 수 있는지 먼저 확인해.
현재 도구가 할 수 있는 작업, 할 수 없는 작업을 구분해.
영상 렌더링이 불가능하면 편집했다고 말하지 말고 편집 결정 목록을 만들어.
파일 접근, 폰트, 자막 엔진, 오디오 계측 등 필요한 기능이 없으면 표시해.
유료 처리·외부 업로드·게시가 필요하면 그 단계는 실행 전에 알려줘.

[말과 컷]
문장의 뜻·화자의 의도·사실관계를 유지해.
조건, 부정어, 숫자, 예외, 질문의 맥락을 자르지 마.
말실수는 이어서 다시 정확히 말한 부분이 있을 때 그 부분을 우선 사용해.
반복은 정보가 같을 때만 줄이고, 의도한 강조와 사례는 보존해.
침묵은 [예: 0.8초 이상인 구간을 검토 후보]로 찾되,
숫자만으로 전부 삭제하지 말고 호흡·강조·실습 대기인지 먼저 판단해.
말의 시작과 끝, 받침, 들숨이 어색하게 잘리지 않게 조정해.
문장 순서를 바꾸면 원본 구간과 바꾼 이유를 편집 목록에 남겨.

[화면]
인물은 [예: 얼굴과 손을 포함한 구도]로 유지해.
세로로 재구성할 때 얼굴·손동작·시연의 핵심 화면이 잘리지 않게 해.
크롭으로 중요한 정보가 사라지면 전체 화면 삽입이나 다른 구도를 사용해.
화면 변화는 주제 전환·핵심 설명·시연 시작처럼 이유가 있는 곳에 넣어.
B롤은 말의 내용을 실제로 설명하는 구간에만 넣고, 원래 음성은 이어가.
보충 영상이 없으면 없는 장면을 촬영 사실처럼 만들지 마.
제공한 자료를 우선 사용하고 추가 자료는 라이선스를 확인해.
전환은 기본 하드컷. 시간·장소 변화 등을 표현할 때만 다른 전환을 사용해.
키프레임 움직임은 시작·종료 위치와 지속시간을 정하고, 필요하면 이즈 인/아웃을 적용해.

[자막]
말의 뜻을 보존하고 [원문형/의미 단위 요약형]으로 작성해.
고유명사·숫자·단위·부정어는 전사와 실제 소리를 대조해.
확신할 수 없는 단어는 임의로 확정하지 말고 검수 목록에 넣어.
한 화면 [예: 2줄 이내]를 시작 기준으로 하되, 모바일에서 실제 가독성을 확인해.
중요 시연·얼굴·플랫폼 UI와 겹치지 않게 위치를 조정해.
선택한 출력 비율과 업로드 플랫폼의 실제 UI를 기준으로 안전영역을 확인해.
[자막 파일 SRT/VTT / 영상에 구워 넣기] 중 요청한 형식으로 전달해.

[소리]
말소리 이해를 우선해. 잡음 제거 후 목소리가 금속성으로 변하는지 확인해.
배경음악은 말할 때 낮추고 문장 사이에서 자연스럽게 회복시켜.
음악은 대화를 덮지 않게 귀로 확인하고 시작·끝에는 짧은 페이드를 적용해.
원본과 결과의 [통합 LUFS / 최대 true peak]를 측정할 수 있을 때만 수치를 보고해.
목표값이 필요하면 용도에 맞는 제안을 먼저 내고, 확정한 값으로 처리해.
측정 도구가 없으면 음량 기준을 통과했다고 단정하지 마.

[색]
노출과 화이트밸런스를 먼저 맞추고 서로 이어지는 컷의 피부색을 일치시켜.
그 뒤 [자연스러운 색/참고 영상의 분위기]로 그레이딩해.
입력 색공간·감마와 LUT 호환을 확인하고 LUT로 모든 문제를 해결하려 하지 마.
HDR 원본이면 SDR/HDR 출력 방식을 먼저 확인해. 임의 변환하지 마.

[출력과 검수]
플랫폼의 현재 공식 업로드 지침과 원본 조건을 확인해 출력값을 정해.
원본을 덮어쓰지 말고 결과를 별도 파일로 저장해.
먼저 대표 구간 [예: 30~60초]를 시안으로 만들어 스타일을 확인할 수 있게 해.
완성본은 처음부터 끝까지 재생해 자막·검은 화면·소리·끊김을 확인해.
자동 검사만 가능하면 사람이 재생 검수한 것처럼 말하지 마.
최종 파일과 편집 목록, 미해결 항목을 함께 줘.
```

## 3. 용도별 추가 지시

공통 지시문 뒤에 필요한 블록 하나를 붙이세요. 서로 충돌하는 수치를 여러 블록에서 동시에 지정하지 마세요.

### A. 강의·화면 시연

```text
강의 다시보기용으로 편집해줘.
설명 → 클릭 → 결과 확인의 순서를 보존해.
수강생이 읽고 따라 할 시간은 일반 침묵과 구분해 유지해.
실습 대기를 줄이면 안내 자막을 넣고 결과가 나타나는 순간을 보존해.
기술 점검·연결 오류·동일한 안내 반복은 제거 후보로 표시해.
커서가 가리키는 메뉴와 입력값은 자막·크롭·확대에 가려지지 않게 해.
화면 확대는 해당 메뉴를 찾고 실행할 때만 사용하고, 이후 전체 맥락으로 복귀해.
처음 등장하는 전문용어에는 짧은 풀이를 추가해.
계정·개인정보·키·비공개 URL이 보이는 구간은 가린 뒤 실제 프레임을 검수해.
```

### B. 설명형 유튜브·토킹헤드

```text
설명형 유튜브용으로 편집해줘.
도입에는 시청자가 얻는 결과를 실제 본문 근거로 짧게 보여줘.
본문에 없는 약속이나 성과를 도입에 새로 만들지 마.
정보가 겹치는 반복은 줄이고 주장·근거·사례·결론의 연결을 보존해.
강조 지점에서만 가벼운 펀치인이나 관련 B롤을 사용해.
매몇초마다 강제 확대하는 방식보다 설명의 단위 변화에 맞춰 화면을 바꿔.
J컷·L컷은 소리가 장면을 자연스럽게 이어줄 때 사용해.
시청자가 핵심을 이해한 뒤 요청한 행동을 알 수 있게 마무리해.
```

### C. 세로 쇼츠

```text
세로 쇼츠용으로 원본에서 독립적으로 이해되는 한 가지 주제를 골라줘.
초반에 핵심 질문이나 결과를 제시하되 원본의 의미를 과장하지 마.
원본의 부정·조건·예외를 빼서 결론이 달라지지 않게 해.
9:16으로 재구성하고 얼굴·핵심 시연이 프레임 안에 남는지 확인해.
자막은 모바일에서 한 번에 읽을 수 있는 의미 단위로 나눠줘.
잘려 나간 맥락을 보충할 때는 원본 근거가 있는 내용만 사용해.
플랫폼 UI가 가리는 영역을 실제 미리보기로 확인해 자막을 옮겨줘.
끝맺음은 문장을 완성하고, 반복 재생을 위해 의미를 억지로 끊지 마.
```

## 4. 한 구간만 수정할 때

```text
대상은 [원본/현재 출력본]의 [시작–끝 타임코드] 구간이야.
문제: [예: 말은 이어지는데 화면 전환이 너무 갑작스러워].
원하는 변화: [예: 다음 장면 소리를 먼저 들려주는 J컷으로 연결].
정도: [예: 새 소리를 약 0.3초 먼저 시작하는 시안].
보존: [문장 전체 / 음악의 박자 / 중요 화면].
이 구간만 바꾸고 다른 구간은 유지해.
변경 전후 구간과 적용한 편집값을 알려줘.
```

여기서 0.3초는 시안용 선택입니다. 효과를 본 뒤 늘리거나 줄이세요.

## 5. AI가 돌려줘야 할 편집 결정 목록

| 번호 | 원본 파일 | 원본 시작–끝 | 작업 | 이유 | 출력본 시작–끝 | 검수 상태 |
|---|---|---|---|---|---|---|
| 예시 | take01.mp4 | 00:01:12.000–00:01:18.400 | 같은 말의 첫 번째 시도 제거 | 뒤에서 같은 내용을 정확히 다시 설명함 | 삭제 구간: 해당 없음 | 문맥·소리 확인 필요 |

- 삭제 전 타임코드는 **원본 기준**, 결과 위치는 **출력본 기준**으로 분리합니다.
- 표기는 `HH:MM:SS.mmm`를 쓰면 프레임 번호와 혼동이 적습니다. 프레임 단위 `HH:MM:SS:FF`를 쓰면 FPS와 DF/NDF도 함께 표시합니다.
- 컷 수, 길이, 자막 수를 보고할 때는 실제 저장된 결과에서 센 값인지 밝혀야 합니다.
- 미지원 작업·부정확한 전사·없는 소스·계측하지 못한 항목은 별도 목록에 둡니다.

## 6. 결과 검수 질문

1. 원본과 비교했을 때 말의 뜻과 조건이 같은가?
2. 음절·호흡·문장 끝이 잘리지 않았는가?
3. 필요한 얼굴·손·버튼·입력값이 보이는가?
4. 자막의 숫자·이름·부정어가 정확한가?
5. 실제 휴대폰 크기에서 자막이 읽히고 UI에 가리지 않는가?
6. 말소리가 음악에 묻히거나 잡음 제거로 손상되지 않았는가?
7. 컷을 넘을 때 색·음량이 튀지 않는가?
8. 출력 파일이 요청한 크기·길이·프레임레이트로 열리고 끝까지 재생되는가?

이 문서는 지시문입니다. 특정 AI 편집 도구에서 모든 작업의 실행을 보장하지 않으므로, 먼저 실행 가능한 기능을 확인하세요.
