## 1. 렌더 계약

- 모든 프레임은 `draw(frame)` 또는 `seek(t)`의 **순수 함수**다. `Math.random`, `Date`, `requestAnimationFrame` 상태, CSS 애니메이션, 누적 물리를 쓰지 않는다. 프레임은 병렬·역순으로 렌더돼도 같아야 한다.
- 난수는 이름 키로 시드한다: `rngFor("ant/body")`. 프레임 번호로 시드하지 않는다.
  ```js
  function hash(s){let h=2166136261;for(const c of s){h^=c.charCodeAt(0);h=Math.imul(h,16777619);}return h>>>0;}
  function rngFor(k){let a=hash(k);return()=>{a=a+0x6D2B79F5|0;let t=Math.imul(a^a>>>15,1|a);t=t+Math.imul(t^t>>>7,61|t)^t;return((t^t>>>14)>>>0)/4294967296;};}
  ```
- 떨림(boil)은 결정이지 기본값이 아니다. 쓴다면 4프레임마다 시드 교체(초당 7.5~12회). p5 방식: `randomSeed(1000 + Math.floor(T*BOIL)); noiseSeed(77);`
- 스프링은 닫힌 형태의 계단 응답으로 계산한다. 목표가 여러 번 바뀌는 값은 변경마다 스프링 하나씩을 더한 합으로 만든다. 그래야 시간의 순수 함수로 남는다(twoclipping). 구현: `engines/code-film/javascript-animation/templates/motion.js`(`spring`·`track`·`indicator`·`swapAlpha`·`loopT`, 프리셋 4종의 오버슈트·정착 시간 실측 포함).
- **우리 엔진(`engines/code-film`, render.mjs)의 계약**: 페이지가 `window.draw(frame)`, `window.FRAMES`, `window.FPS`를 내보내고, 선택으로 `window.CUES=[초,...]`(컷·타격 시점, sync-check용)와 `window.SCORE=ac=>{...}`(OfflineAudioContext 사운드)를 둔다. render.mjs는 `?render`로 페이지를 열고 `ready`를 기다리지 않는다. 그래서 폰트는 시스템 설치 폰트만 쓰고(동기 사용 가능), 무거운 초기화는 스크립트 로드 시점에 끝낸다.
- 참고(다른 하니스): riso·opus-js는 `{duration, ready, seek, renderAudio, marks, shots}` 계약을 쓴다. 우리 엔진과 섞지 않는다.
- 실시간 화면 녹화 금지(프레임 드롭). 인코딩은 스테이징에서 하고 성공한 뒤에만 교체한다.

## 2. 구조

1. **코드보다 비트시트 먼저.** 비트마다 끝 상태(시청자가 가리킬 수 있는 것), 카메라, 노출, 사운드 큐를 적는다. "코드 안에서 디자인하면 슬라이드가 된다."
2. **타이밍 정본은 하나.** `BPM, SECTIONS, SHOTS, EVENTS`를 한 곳에 둔다. 그림과 소리가 같이 읽는다. 두 번째 타이밍 상수 금지.
3. **길이에 맞춘 장면 수**: 30초 미만은 한 장면·한 테이크, 30~60초는 1~3 무브먼트, 샷 1.4~4초.
4. **모든 비트는 앞 비트가 원인.** "A 하고 B를 본다"가 아니라 "A가 B를 일으킨다".
5. **명사를 그리지 말고 행동과 결과를 계획한다.** 샷이 바꾸는 게 렌더링뿐이면 자르거나 합친다.
6. **컷은 정보를 더할 때만.** 같은 걸 크게 보려면 카메라를 움직인다. 컷을 가로질러 무언가를 이어간다(같은 오브젝트, 같은 색).
7. **세트를 만들지 카드를 만들지 않는다.** 샷마다 무언가가 일어난다. 텍스트는 가볍게.

## 3. 타이밍

- **기본값은 다이내믹이다(광고·쇼릴·소개 영상 기준).** 멈춰서 붙잡지 않는다: 가장 긴 정지 0.5초 이하, 끝 카드도 계속 움직여 완전 정지는 1초 이하. 설명·UI 영상도 카메라 펀치 줌·휩 전환·배경색 전환으로 10초당 3.5컷 이상. 차분한 템포는 요청이 있을 때만. 측정: `scripts/edit/energy.sh`.

- **Snap, then hold**: 변화는 0.04~0.07초, 이징은 안착 구간에만.
- 컷 길이 0.8~2.7초, 스태거 0.05~0.14초. 핵심 비트는 샷 가운데.
- 동작 도중에 들어가고 마지막 비트에서 나온다. 꼬리 정지는 느리게 읽힌다.
- **0프레임은 구성된 밝고 움직이는 화면.** 검정에서 페이드인 금지. 새 샷도 첫 프레임이 비어 있으면 안 된다(우리 테스트에서 컷 직후 0.2초가 빈 화면이었음).
- 마지막 이벤트 뒤에는 읽을 시간을 주되 정지로 주지 않는다. 끝 카드는 2초 안에서 계속 미세하게 움직인다(정지 1초 이하).
- 주기 동작은 프레임당 π보다 훨씬 작게 움직인다. 사이클은 속도 0에서 서서히 올린다.
- 시간을 재매핑하면 그 구간 전체에 적용한다(원시 `t` 사용처를 검색).

## 4. 렌더 품질

- 빠른 이동: 셔터 샘플 모션블러. 3px 이동당 1샘플, 최대 10~24, 셔터 90%. 또는 프레임당 4서브프레임 + ffmpeg `tmix`(twoclipping, 60fps).
  - 우리 엔진: `render.mjs ... --sub N [--shutter 0.5]`가 어떤 페이지든 서브프레임을 평균한다(페이지 `draw()`가 소수 프레임을 받아야 함). 예제 3편처럼 페이지가 자체 블러를 하면 쓰지 않는다(이중 블러). 실측(2026-09-28): 프레임당 약 100px 이동에서 `--sub 4`는 네 겹 계단이 보이고, `--sub 12`는 매끄럽다. 그리는 비용은 N배.
- 공간 안티앨리어싱: 2배로 그린 뒤 lanczos 축소(`--ss 2`).
- 카메라가 스케일하는 요소에 `will-change` 금지(텍스트가 흐려진다). 모핑 컨테이너 안에서 바뀌는 텍스트는 자기만의 등장·퇴장 타이밍을 둔다.
- 루프 영상은 마지막 프레임이 첫 프레임과 같아야 한다(커서 위치·속도까지).

## 5. 디자인

- 요소는 적게, 렌더링은 풍부하게. 표면은 base → texture → edge 세 층.
- 텍스트 블록 위치는 영상 전체에서 하나. 1080 폭 기준 본문 약 44px, 제목 64~80px, 줄 길이 800px 이하. 60px 이상·1.2초 이상 노출·90px 안전 여백(Soham 템플릿).
- 텍스트 겹침 0(`layout-check.mjs` CLEAN).
- 스타일 바이블은 매 세션 원문 그대로 붙인다(바꿔 쓰면 흔들린다).
- 흔한 AI 기본값을 피하려면 명시적으로 금지한다: 크림 배경, 제목 이탤릭 강조어, 01/02/03 번호 라벨, 모노스페이스 라벨, 알약 버튼(Anthropic 공식 프롬프팅 가이드 예시). 쇼릴 프롬프트 결과가 서로 비슷해지는 이유다.
- 금지 목록 예(twoclipping): 튀는 이징, 파티클 폭발, 글로우, UI 크롬 그라디언트, 아이콘 선 굵기 불일치, 죽은 시간, 템플릿 느낌.
- 업로드본에 움직이는 그레인 금지(인스타에서 품질 1/3 손실). 30fps, 플랫폼 해상도 정확히.

## 6. 사운드

- 기본은 페이지 안 Web Audio `OfflineAudioContext`. 48kHz 스테레오, 길이는 영상과 정확히 같게.
- **사운드는 그림 타임라인에서 파생한다.** 접촉 약 30ms 전(단, 0초 미만이 되지 않게 `Math.max(0, t-0.03)` — 실측에서 나온 버그). 늦게는 40ms 이내, 20ms보다 먼저 두지 않는다.
- 라우드니스는 렌더 후 정적 게인이나 loudnorm 한 번(`master.py`): -16~-14 LUFS, TP ≤ -1. 컴프레서로 맞추지 않는다(엔진마다 다름).
- 컷은 볼륨이 아니라 **화성**으로 표시한다. +6dB 넘는 점프는 놀람(STARTLE). +3~5dB와 코드 변화면 깔끔한 편집으로 읽힌다.
- 레이어는 한 마디에 1~2개씩. 한 번은 브레이크를 둔다.
- 연필 긁는 소리 같은 연속 배경음 금지. 그리는 동작은 무음, 접촉에만 소리.
- 곡을 받으면 numpy/librosa로 비트 그리드를 분석하고 다운비트에서 시작한다. 그림이 음악을 따른다.
- 사용자 음원은 손대지 않는다. 자르는 곳은 zero crossing, EQ·정규화 금지.
- 음악 없이 소리를 못 들으면 "미청취"를 명시하고 사람이 들을 시점 3~5개를 지목한다.

## 6-1. 15초 사운드 레이어 레시피 (놀람 점프 +6dB 방지)

120BPM 기준 1마디 = 2초, 15초 ≈ 7.5마디.
- 0~2초: 패드 1개만(조용한 도입). 하이햇·크래시 금지. 조용한 도입부에 고역 타격이 있으면 loudnorm이 도입부를 끌어올리다 AAC에서 트루피크가 +6.9dBTP까지 튄 실측이 있다.
- 2~4초: 킥 추가. 4~6초: 베이스 추가.
- 6~10초: 하이햇 처음 추가. 컷은 화성 변화로 표시.
- 10~12초: 한 마디 브레이크(레이어 1~2개 빼기).
- 12~15초: 전 레이어 + 끝 카드 해소 화음, 마지막 1초는 여운.
- 새 레이어 진입은 +3~5dB 이내. `sync-check.mjs`가 STARTLE을 내면 그 시점 레이어 하나를 다음 마디로 미룬다.

## 7. QA

1. `asset-audit.mjs page.html` → CLEAN(외부 로드 0)
2. 비트당 한 프레임 스틸(`render.mjs page.html shot --stills ...`) → 격자·가독성 확인 후 전체 렌더
3. `render.mjs page.html sheet.jpg --sheet 0.5` 컨택트시트, `--phone 2` 폭 360px 판독 시트, 빠른 구간은 `--strip <초>` 연속 12프레임, 1:1 크롭
3-1. `render.mjs page.html --check`: 같은 프레임을 다른 순서로 두 번 그려 픽셀을 비교(DETERMINISM), 첫·끝 프레임 차이(LOOP SEAM, 루프 영상만 1% 미만). Chrome은 자주 읽히는 캔버스를 GPU에서 CPU 래스터로 바꾸며 글자 가장자리가 달라지므로, render.mjs는 시작 전에 캔버스를 예열한다(실측: 예열 전 0프레임 글자 가장자리 최대 56단계 차이, 예열 후 0)
3-2. 디렉터 채점 루프: `qa-gate.md` E(7항목 1~10점, 전 항목 8점 이상까지)
4. `layout-check.mjs` CLEAN, `sync-check.mjs out.mp4` 전 이벤트 ±100ms·놀람 0
5. `master.py` → `qa_check.sh` FAIL 0 (프레임 수 = 길이 × fps)
6. 인코딩된 MP4를 다시 시트로 보고(깜빡임·뭉개짐은 MP4에서만 보인다) 결과 보고
7. "기술 통과는 예술적 승인이 아니다." 무엇을 봤고 무엇을 못 봤는지 적는다.
