# 모션 레퍼런스 (사이트·공개 사례·문법)

모션그래픽이 평범하다는 평가가 나오면 규칙을 더 넣지 말고 레퍼런스를 바꾼다(`reference-breakdown.md`). 이 문서는 우리가 실제로 쓰던 레퍼런스와, 그 영상에서 뽑은 움직임 문법이다.

- 원본 영상 파일은 복사하지 않았다. 아래 공개 주소에서 직접 보고, 분석용으로만 내려받는다(재배포·화면 복제 금지). 가져오는 것은 **움직임 문법**(샷 순서·타이밍·전환)뿐이다. 로고·캐릭터·구도·문구는 가져오지 않는다.
- 예시 숫자·후기는 지어서 쓰지 않고, 화면에 "예시"로 표기한다.

## 3. 쇼츠·릴스 틀 (토킹헤드 위에 그래픽)

| 틀 | 구조 | 쓰임 |
|---|---|---|
| 레퍼런스2: 어두운 카드형(유튜브 쇼츠 채널 oDW7XUrzork) | 얼굴 없는 어두운 화면 카드 그래픽 약 60% / 위 그래픽·아래 얼굴 분할 약 30% / 얼굴 약 10%. 장면 1.7초마다 전환, 항목마다 "0N / 05" 머리글 + 이름 타자, 굴러가는 카운터, 자막은 화면 가운데 2~3어절 한 덩어리 | "공식 5가지"처럼 항목이 반복되는 정보형 |
| 레퍼런스3: 번호 표지 + 카드 확대형(릴스 채널 nick_saraev) | 항목마다 흰 바탕 번호 표지(띠 안 명조 기울임) → 같은 카드 확대(흐린 얼굴 배경, 형광펜, 숫자 팝) → 아래 둥근 얼굴 창, 자막은 단어가 하나씩 쌓이고 강조어만 명조 기울임 | 번호 목록형 |

두 틀 모두 항목마다 같은 화면 구조를 반복하고 내용만 바꾼다. 색은 학생의 브랜드 색으로 바꾸고, 레퍼런스 채널의 캐릭터·채널명은 쓰지 않는다. 자막·효과음 규칙은 `shorts-rules.md`, 따라 하기 절차는 `reference-clone.md`.

## 4. 문법 (원자료 표현 그대로)

시간 격자
- "1박 = 0.5초, 1마디 = 2초(120BPM). 컷은 모두 박 위."
- "0.5초 색 컷 5연타 + 티커 띠 + 슬램"
- "0.25초 간격 타이포 연타, 굵기 900·300 교대" / "연타마다 clack"
- "0프레임부터 움직이는 구성 화면." 검정에서 페이드인하지 않는다.
- 히트마다 펀치: "큰 글자가 오른쪽에서 고속 진입(서브프레임 블러 8), 11.25 펀치, 11.55 왼쪽으로 휩". 히트(컷·타격) 순간마다 확대 펀치·휩 중 하나를 준다. 히트 시각은 `window.CUES`에 한 곳으로 적는다.
- 효과음은 히트마다, 큰 소리로 깔지 않는다: 클릭·타이핑 정도의 작은 소리, 음악은 낮게(강의형). 개수로 정하지 않고 상황으로 정한다(`shorts-rules.md` 4장).

스프링
- "heavy: 큰 글자·로고, 오버슈트 0 / base: 카드·카메라 / snappy: UI·커서 / playful: 마스코트"(`motion.js`). 큰 글자에 playful을 쓰면 줄끼리 겹친다(실측).
- "폭 압축: 가로 1.9배 → 0.8 → 1.08 → 0.92 박마다 스냅(track)" 같이 값이 여러 번 바뀌면 `track()`으로 합산한다.
- "하이라이트는 앞 가장자리가 더 빠르게 늘어나며 이동(indicator)".
- 스프링 이름과 수치: snappy 0.8% 오버슈트 / 0.23초 정착, base 0% / 0.44초, heavy 0% / 0.58초, playful 23% / 0.59초.

전환과 연속성
- "매치 컷": 나가는 전환은 항상 "무엇이 다음 장면의 무엇이 되나"를 적는다(예: 점 → 레일 점 → 아이리스 중심 → 도형 중심).
- "주인공 오브젝트 하나가 컷을 가로지른다"(점, 알약, 마스코트).
- 전환 종류: 아이리스, 슬릿, 사선 와이프, 픽셀 디졸브, 줌 스루, 매치 컷. 단순 크로스페이드 금지(광고·쇼릴).
- 빠른 이동은 서브프레임 모션블러(`render.mjs --sub 8`).

디자인 시스템
- "네 모서리 HUD(타임코드·프레임 번호)", "배경 60px 점 격자", "텍스트 블록 위치 고정", 배경 2종·강조 3종·전환 1종(쇼츠 틀).
- 텍스트는 1080 폭에서 60px 이상, 1.2초 이상 노출, 90px 안전 여백.
- 라벨은 모바일에서 읽히게 30px 이상.

호흡
- 광고·쇼릴·소개 영상: 다이내믹. 가장 긴 정지 0.5초 이하, 10초당 컷 3.5 이상(`energy.sh`).
- 강의·튜토리얼·설명(교육): 정적에 가깝게, 실제 화면과 비슷한 재현 장면 많이, 컷은 섹션 경계 위주(`energy.sh --mode calm`). 소개·홍보 영상에 이 규칙을 쓰면 "평범하다"는 평가가 나온다. 용도로 갈라 쓴다.
- 정보형 릴스: 효과보다 말에 집중. 장식을 빼면서 말에 맞춰 쌓이는 움직임까지 지우면 "너무 정적"이 된다.

## 5. 이 문서를 쓰는 순서

1. 영상 용도를 정한다(쇼릴·제품 소개·앱 시연·데이터·SNS 광고·캐릭터·쇼츠).
2. 위 2·3장 표에서 같은 용도의 레퍼런스를 고르거나 1장 사이트에서 새로 찾는다.
3. 4장 문법 중 해당하는 줄을 비트시트에 옮긴다(시간 격자, 히트 시각, 스프링 종류, 나가는 전환).
4. 렌더 후 `qa-gate.md` E의 채점 루프로 7항목을 매긴다.
