# 쇼츠·릴스 편집 규칙 (실측으로 정리)

토킹헤드 원본으로 세로 쇼츠·릴스를 만들 때 쓴다. 레퍼런스 스타일을 따라 할 때는 `reference-clone.md`도 같이 본다. 실측 사례: 릴스 v007~v010, 조쉬 구조판, 레퍼런스2·3 구조판.

## 1. 기본 틀
- 다음 쇼츠·릴스는 레퍼런스2(어두운 화면 카드형) 또는 레퍼런스3(번호 표지 → 카드 확대 → 둥근 얼굴 창)로 시작한다(선택된 기본 틀). 틀 설명은 `reference-clone.md` 7장.
- 항목(공식 N가지 등)마다 같은 화면 구조를 반복하고 내용만 바꾼다.

## 2. 자막
- **한 단어씩** 말에 맞춰 나타난다. 단어별 시간은 정밀 전사에서 가져오고, 문구는 오인식을 고친 문장을 쓴다.
- **짧게 끊는다**: 한 덩어리 2어절 이하(긴 단어 5자 이상은 혼자). 문장 끝과 "첫째·둘째", 새 문장 시작 앞에서 반드시 끊는다(실측: "공식 첫째"처럼 문장을 넘어 묶였던 것).
- **위치는 끝까지 같은 자리**: 배치가 바뀌어도 y 고정. 틀이 정한 자리를 따른다(경계 자리, 화면 가운데 등).
- **크기는 크게**: 1080 폭 기준 84~93px(기존 62px의 1.5배 요청). 밝은 배경은 진한 글씨, 얼굴·어두운 배경은 흰 글씨+검은 테두리. 강조어만 색(기본 강조색/노랑).
- 컷으로 잘린 구간에 걸린 단어는 컷이 끝나는 시점으로 옮긴다(안 옮기면 자막이 빠진다).
- 그래픽 위 띠·라벨이 자막 자리와 겹치면 띠를 뺀다. 자막이 같은 말을 하면 띠는 중복이다.

## 3. 산만함과 정적 사이
- **산만하게 만드는 것(빼기)**: 큰 글자 튀기, 얼굴 확대 펀치, 장면마다 지나가는 패널, 카메라 흔들림·회전, 시간 간격만 맞춘 효과음. 실측: v007 효과음 분당 46개·그래픽 2.3초마다 → "산만".
- **정적으로 만드는 실수(지우지 않기)**: 장식을 빼면서 장면 안에서 말에 맞춰 쌓이는 움직임(카운터, 목록 체크, 카드 이동, 토글)과 느린 확대까지 지우면 정적이 된다. 실측: v009 → "너무 정적".
- 움직임은 수치로 맞춘다: `scale=108:192,fps=10,signalstats` YDIF 평균. 참고 범위 조쉬 5.2~6.1 / nick 5.8 / 게으른빌더 8.5. 우리 v009(정적) 3.37, v007(산만) 7.27. 고른 틀의 레퍼런스 값에 가깝게.
- 장면 안 요소는 말에 맞춰 0.3~1초마다 하나씩 쌓는다. 새 장면 전환 주기는 틀을 따른다(레퍼런스2 약 1.7초, 레퍼런스3 약 3초).

## 4. 효과음: 개수가 아니라 상황으로
- 개수·분당 상한을 목표로 두지 않는다. 장면마다 "이 순간에 소리가 있어야 하나"로 정한다. 숫자를 채우려고 넣으면 v007처럼 산만해진다.
- 넣는 순간: 보는 사람이 알아채야 할 변화가 화면에 생길 때. 결과 공개(완료·숫자 확정), 항목·장면 전환, 누르기·토글 같은 행동, 강조할 반전.
- 빼는 순간: 같은 종류 변화가 연달아 나올 때(첫 번째만), 핵심 단어와 겹쳐 말을 가릴 때, 화면 변화 없이 간격만 채울 때, 차분히 들어야 하는 설명 구간.
- 소리 종류를 사건에 맞춘다: 등장 pop, 이동·전환 whoosh, 누르기 click. 같은 소리를 기계적으로 반복하지 않는다.
- 실측: 레퍼런스2 구조판 v001(레퍼런스 밀도에 맞춘 13개) vs v002(이 기준으로 고른 10개, 반복 머리글 전환 4개 뺌·확정 순간으로 옮김·빠진 결과 공개 추가)를 나란히 듣고 v002를 선택. 레퍼런스3 구조판도 v001(19개) vs v002(11개, 반복 번호 표지·확대 whoosh 6개, 0.6초 안에 겹친 click, 같은 항목 연달은 팝 뺌)에서도 v002를 선택.
- 레퍼런스 밀도는 참고만 한다(레퍼런스2 추정 분당 약 28, 레퍼런스3 추정 20~32, 산만했던 v007 46).
- 목록은 html `window.SFX` 한 곳에 두고, 믹스 스크립트가 거기서 읽게 해서 고친 뒤 소리만 다시 섞을 수 있게 한다.
- 보고에는 개수 대신 효과음 목록(시각·종류·붙은 사건)을 적고, 일부러 넣지 않은 자리와 이유를 1~2개 적는다.

## 5. 원본에서 다시 자를 때
- 문장 단위로 구간을 고르고(EDL json), 다시 말한 구간(`retake_check.py`)은 쓰지 않는다. 대사는 원본에 있는 말만.
- 잘라 붙인 소리를 mlx-whisper로 다시 받아써서 빠진 말·끊긴 문장을 확인한다(실측: "뽑은"이 빠진 것을 잡음).
- 얼굴 패널·창은 클로즈업 원본이면 눈만 나온다. 같은 컷의 가로 원본(머리~어깨)에서 자른다.

## 6. 전후 비교 영상(글에 붙일 실물 미디어)
- 같은 촬영본·같은 타임라인으로 전/후 두 버전을 만들고, 같은 구간을 가로 1920x1080에 나란히 놓는다. 같은 구간을 두 번 재생해 처음엔 왼쪽 소리, 다음엔 오른쪽 소리, 소리 나는 쪽만 밝게.
- 화면 차이가 큰 구간을 고른다: v007·v008처럼 효과음만 다르면 화면이 거의 같다. 두 영상의 프레임 차이(blend difference YAVG)를 초 단위로 재서 차이가 큰 구간을 쓴다.
- 이름표는 "전/후"와 실측 숫자(효과음 개수 등)만. 설명 애니메이션은 넣지 않는다.

## 7. 썸네일
`reference-clone.md` 4장 체크리스트를 보여주기 전에 전부 확인한다(인물 앞·아이콘 뒤 레이어 순서, 실물 로고, 글씨·띠 실측, 나란히 비교 이미지와 확대 확인).
