# 검증된 프롬프트 형태 (공개 게시물에서 추린 요지)

원문을 그대로 붙여 넣지 않는다. 구조(목표·길이·기준·금지·검수)를 가져와 학생 주제로 바꾼다. 더 많은 사례와 프롬프트는 `motion-references.md`의 Prompt Motion 사이트에서 찾는다.

## 1. 한 줄 쇼릴 (수십 명이 복제한 형태)

```text
make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.
```
목표(쇼릴)·길이(15초)·기준("go all out")만 주고 나머지는 모델에 맡긴다. 결과는 매번 스위스 타이포·챕터 번호·HUD·이징 시연이 들어간 비슷한 문법이 된다. 차별화가 필요하면 2번 구조형으로 간다. 변형: "for {제품}", "Do your research on {제품} first".

## 2. 6단계 런치 영상 구조 (30~45초, 사운드 포함)

1. **조사**: 제품 링크와 기능·가격·소개 페이지를 읽는다. 제품명, 한 줄 가치, 핵심 기능 3~5개, 대상, 실제 수치, 브랜드 색(hex)과 글꼴을 뽑는다. 사이트에 있는 주장만 쓴다. 지어낸 수치·후기·로고 금지.
2. **스토리보드 먼저, 코드 나중**: 훅(0~3초, 6단어 이하) → 긴장(3~8초, 문제를 눈에 보이게) → 공개(8~12초, 제품명이 큰 임팩트로) → 기능(기능마다 장면 하나, 4~6초, 장면마다 다른 기법: 글자 모션·도형 모핑·격자 리듬·파티클·가짜 3D·도형으로 만든 UI·숫자 카운트업) → 끝 카드(마지막 4~5초, 이름·가치·주소, 2초 이상 유지). 표로 적는다: 타임코드, 화면 텍스트(7단어 이하), 비주얼, 모션 기법, 나가는 전환, 사운드 큐.
3. **모션 규칙**: 컷은 모두 설계된 전환(아이리스·슬릿·사선 와이프·픽셀 디졸브·줌 스루·매치 컷), 단순 크로스페이드 금지. 이징은 expo·back·elastic·bounce, 등속은 느린 드리프트에만. 그룹은 스태거, 오버슈트와 후속 동작, 잔상. 글자는 1080p에서 60px 이상, 1.2초 이상, 90px 안전 여백. 이모지·스톡 아이콘·실존 인물·저작권 캐릭터 금지. UI는 단순한 벡터 도형으로 그린다.
4. **빌드**: 단일 HTML, 캔버스 하나, 모든 프레임은 시간만으로 정해지는 순수 함수 `render(t)`(프레임 사이 상태 없음, 난수는 시드). 장면 타이밍은 한 곳의 상수에 둔다. 미리보기 컨트롤(재생·스크러버·타임코드·소리 토글).
5. **사운드**: 장면과 같은 타임라인 상수를 읽어 모든 타격이 그 프레임에 닿게 한다. 효과음은 이벤트마다(라이저·임팩트·휘익·플럭·팝). 피크 -1 dBFS 아래, 클리핑 없음.
6. **렌더와 QA**: 헤드리스 브라우저로 프레임별 렌더 → ffmpeg(H.264, yuv420p, AAC, faststart). 컨택트시트 약 10프레임으로 잘린 글자·겹침·빠진 글꼴·브랜드 색을 확인하고, 길이와 소리 크기를 재고, 고쳐서 다시 렌더한다. 납품: MP4, HTML 소스, 스토리보드 표.

학생 환경에서는 렌더를 `engines/code-film`(또는 HyperFrames·Remotion)으로 하고, 배경음은 학생이 받아 둔 파일만 쓴다(`SKILL.md` 6-1).

## 3. UI 모핑 모션 (14~16초, 컷 0)

하나의 도형이 버튼 → 입력칸 → 로더 → 체크 → 카드 → 차트 → 명령 팔레트 → 토스트로 계속 변형된다. 120BPM, 박마다 상태 변화. 한 파일 HTML, 시간 t로 프레임을 결정(seek). 전체 렌더 전에 박자당 한 프레임씩 확인해 가독성·타이밍을 고친다. 루프로 만들면 마지막 상태가 첫 상태와 위치·속도까지 같아야 한다. 상태 목록 표(박·시각·상태·컨테이너 크기·카메라·커서·소리)를 먼저 쓴다.

## 4. 토킹헤드를 그림 설명으로 바꾸기

원본 세로 영상에서 사람을 우하단 원형 창으로 줄이고, 말하는 개념마다 선화 B롤을 그린다. 원음·자막·길이는 그대로. 장면은 자막 문장 단위로 약 30개. 코드로 장면을 그리고 `E` 경로로 합성한다.

## 5. 한 줄 요청 예 (기본값으로 구조를 채운다)

- 앱 홍보 30초 세로(1080x1920, 30fps) Apple식 제품 영상
- 이 발표문 블로그 글을 모던하고 펀치 있는 영상으로
- 신용카드를 대는 2초 동안 실제로 일어나는 일, 25~30초 설명
- 하늘은 왜 파란가, 1950년대 과학 교과서 스타일 20초 설명
- 얼굴 없는 채널의 15초 오프닝, 따뜻한 분위기, 채널 이름으로 끝
- 이 시를 낭독하는 20초 릴스

요청이 짧으면 `SKILL.md` 4장대로 빠진 요소(역할·규격·입력·렌더 방식·금지·스타일·리듬·검수)를 기본값으로 채워 브리프에 적는다.
