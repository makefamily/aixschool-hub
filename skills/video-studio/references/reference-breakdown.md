# 레퍼런스 분해 → 재구성 (품질을 가장 크게 올린 방법)

2026-09-27 실측: 같은 기획("직원 구합니다" 15초 광고)을 규칙만 보고 만들었을 때 검수 7점이었다. 9점급 레퍼런스를 0.17초 단위로 분해해 그 문법으로 다시 만들었더니 전환 기법이 2종에서 8종으로 늘었고, 매치 컷으로 한 흐름이 됐다. 생성 영상의 품질이 부족하면 규칙을 더 넣기보다 이 방법을 먼저 쓴다.

## 절차

1. **레퍼런스 고르기**: 같은 길이·비율·장르의 9점급 영상 1~2개. `generation-playbook.md` §6 표 또는 사용자가 준 링크를 쓴다. 받기: `yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o ref.mp4 <URL>`(읽기 전용, 재배포 금지).
2. **분해**: 5초 단위로 6fps 타임코드 시트를 만들어 직접 본다.
   ```bash
   for s in 0 5 10; do ffmpeg -ss $s -t 5 -i ref.mp4 -vf "fps=6,scale=320:-2,drawtext=text='%{pts\:flt}':x=4:y=4:fontsize=18:fontcolor=white:box=1:boxcolor=black@0.7,tile=6x5" -frames:v 1 ref_$s.jpg; done
   ffmpeg -i ref.mp4 -vf "scdet=threshold=8,metadata=print" -an -f null - 2>&1 | grep -o "lavfi.scd.time=[0-9.]*"
   ```
3. **모션 사양서 작성**: 샷마다 [시작~끝 / 배경색 / 주 오브젝트 / 움직임 기법 / 들어오는 전환 / 나가는 전환(무엇이 다음 장면의 무엇이 되나)]. 그리고 전체 규칙: 팔레트, 타이포 3단, HUD, fps, 모션 블러, 후반 연타 구간.
4. **매핑표**: 레퍼런스 샷 → 우리 내용. 기법만 가져오고 로고·캐릭터·구도·문구는 가져오지 않는다.
5. 제작 → 디렉터 패스(스틸) → 전체 렌더 → `sync-check` 15/15 목표 → master → QA.

## 분해 예: Stephan Livera "motion designer" 쇼릴 (15초, 1080p60, P-A 프롬프트 결과)

| 시간 | 배경 | 내용·기법 | 나가는 전환 |
|---|---|---|---|
| 0~1.9 | 잉크 | 점 → 링 → 12갈래 방사 마크, 원형 마이크로 텍스트 회전 | 마크 축소 → 크림 원이 퍼짐(아이리스) |
| 1.9~3.5 | 레드 | 넓은 고딕 워드마크 글자별 상승, 폭 압축 애니메이션, 이탤릭 세리프 부제 | 글자가 하나씩 점으로 바뀌며 빠짐 |
| 3.5~5.6 | 크림 | 에디토리얼 차트 "Six ways to get from A to B": 점 6개가 linear/ease/expo/back/elastic/bounce로 레일 경주, 잔상 | 점들이 모여 파란 타원 → 파란 배경 |
| 5.6~7.5 | 일렉트릭 블루 | 흰 도형 모핑 원→삼각형→별→사각형, 위성 점들이 공전하며 같이 변형 | 사각형 축소 → 검은 배경 타일 |
| 7.5~10.9 | 잉크 | 트루셰 패턴이 타일에서 번짐, 레드 물결 전파 → 3D 점구름(구→도넛) | 점구름 속으로 줌 |
| 11.25~12.65 | 5색 교대 | 0.23초 간격 타이포 연타: EASE / IN(모션 블러) / EASE / OUT. / NEVER 낙하 / NEVER 반복 행 / LINEAR. | 사선 슬랩 + 원이 쓸고 지나감 |
| 13.1~15 | 레드 | 마크 회전 진입 + 파티클, 워드마크 + 이탤릭 부제 + 메타 행, 정지 | — |

전체 규칙: 5색(잉크 #111, 크림, 레드오렌지, 일렉트릭 블루, 라임), 넓은 고딕 + 이탤릭 세리프 + 모노 라벨, 네 모서리 HUD(프레임 표시·타임코드), 60fps, 강한 모션 블러, 스프링 오버슈트, 컷의 대부분이 오브젝트 매치 컷.
