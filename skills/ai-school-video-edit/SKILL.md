# 인물 낭독 숏폼 편집 (기본형 + 5가지 스타일)

학생이 찍은 낭독 촬영본을 받아 선택한 스타일의 속도·글자·자료 문법을 적용한 완성 MP4를 전달하는 것이 목적이다. 분석 메모만 만들고 편집을 끝냈다고 하지 않는다.

## 스타일 (시작값은 `references/styles.json`)
| id | 이름 | 언제 |
|---|---|---|
| `info-cards` | 정보 카드 + 하단 인물 (기본형) | AI 도구, 실행 순서, 비교 설명 |
| `proof-top` | 상단 증거 삽입형 | 한 가지 주장과 구체적 예시를 빠르게 |
| `numbered-talk` | 고정 제목 + 번호 목록형 | 촬영본 하나로 만드는 팁·오해·체크리스트. 자료 없이도 가장 쉽게 된다 |
| `classroom-proof` | 자료 시연형 | 수업·과정·실제 결과물 설명 |
| `build-diary` | 제작일지 몽타주형 | 만드는 과정·하루 이야기. 과정 사진·영상 자료가 따로 필요하다 |
스타일을 말하지 않았거나 "기본형"이라고 하면 `info-cards`를 바로 적용한다. 스타일을 다시 묻거나 비교본만 만들고 멈추지 않는다. 학생의 새 요청이 있으면 그것이 우선이다. 값은 "재현 시작값"이지 원본 편집기 설정값이 아니다. 글꼴은 학생 PC에 있는 것으로 바꿔 쓴다(Pretendard, 맥 Apple SD Gothic Neo, 윈도우 Malgun Gothic).

## 준비
공통 준비(ffmpeg, Node 22, HyperFrames, 받아쓰기, 글꼴)는 `reels-style-router/SKILL.md`의 "공통 준비"를 따른다. 모션그래픽은 `hyperframes`와 `video-studio` 스킬로 만든다.

먼저 학생에게 받는다: 촬영본, 이 영상의 대본(있으면), 머리 위에 고정으로 넣을 제목 문구(시리즈 문구가 있으면 `series_headline`에 넣는다. 없으면 영상마다 함께 정한다), 올릴 곳(릴스, 쇼츠).

## 편집 순서 (AI가 실행)
1. 선택한 스타일의 값만 읽는다. 참고 영상의 가격·주장·끝 호출 문구를 학생 영상에 복사하지 않는다. 학생이 쓰는 수업·상품 정보는 학생이 확인해 준 것만 쓴다.
2. 원본은 보존하고 별도 출력 폴더에 받아쓰기 단어 시간표와 컷 목록(EDL)을 만든다. 반복된 앞 발화와 미완성 테이크는 지우고 마지막으로 끝낸 발화를 남긴다. 숫자·고유명사·부정어는 음성과 대조한다. 앞부분을 기계적으로 지워 뜻이 바뀌지 않게 한다.
3. 무음을 타이트하게 이으며 자음·받침·말끝을 자르지 않는다. 단어 시간 + 무음 검출 + 실제 청취로 정한다. 점프컷 소리 방지용 짧은 크로스페이드는 말이 겹치지 않게만 쓴다.
4. 지운 구간과 남긴 구간, 원본 시간 -> 출력 시간 대응표를 먼저 확정하고 자막·자료·효과음 시점을 전부 그 표로 옮긴다. 원본 시간을 편집 후 영상에 그대로 쓰지 않는다.
5. 머리 위 제목은 새 대사의 문제·반전·약속에 맞춰 쓰고 학생 확인을 받는다. 이어서 스타일에 맞게 한글 뜻 단위로 자막을 나눈다. 한국어는 글자 크기를 줄이기보다 덩어리를 조정한다. 글꼴 이름이 아니라 실제로 그려진 글자 모양과 폭으로 맞는지 본다.
6. 자료 화면이 모션그래픽이면 새 내용에 맞는 카드·도표·화면·글자 움직임을 실제 애니메이션으로 만든다. 정지 이미지에 일괄 확대만 주는 것으로 대신하지 않는다. 그림 컷, 자막 교체, 움직임 시작, 효과음은 별도 이벤트로 적는다(`references/event-benchmark.md`). 효과음·배경음악은 학생이 쓸 수 있는 것만 쓰고 직접 들어 확인하지 못한 것은 "제안 트랙"으로 표시한다.
7. 배경·조명 보정(선택)은 학생이 허락한 범위에서만 한다. 얼굴, 입 모양, 목소리, 손을 바꾸지 않고, 프레임마다 따로 생성해서 깜빡이게 하지 않는다. 실제 수업이나 실제 학생 결과인 척하는 장면은 만들지 않는다.
8. 렌더 후 디코딩 검사, 길이·음성·영상 트랙·해상도·자막 끝·음성 싱크를 확인한다. 시작·중간·끝과 지운 반복 발화 주변은 직접 재생해 본다. 직접 듣지 못했으면 "청취 미확인"으로 적는다.
9. 학생에게 MP4, 고칠 수 있는 계획 파일, 교정한 자막 파일, 쓴 자료 기록을 전한다. 수정 요청은 같은 스타일의 새 버전으로 반영하고 다른 스타일의 모양을 섞지 않는다. 올리는 일은 하지 않는다.

## 인물 분리(선택)
인물만 오려 자료 위에 올리는 스타일은 맥에서는 맥 기본 기능 기반 도구, 윈도우에서는 배경 제거 파이썬 도구(rembg)를 학생 허락 후 설치해 쓴다. 의자 같은 물체가 같이 잡히는지 입력마다 확인하고, 알파(투명 영역)는 최종 MP4에서도 경계를 확인한다.

## 지킬 것
- 외부 게시, 메시지 발송은 이 스킬의 범위가 아니다.
- 공개 카피는 `humanize-scan`으로 AI 티를 점검한다. 외부 사실 주장은 출처를 확인한 것만 쓴다.
- 학생 화면에 터미널 명령과 내 컴퓨터 폴더 경로를 보이지 않는다.
