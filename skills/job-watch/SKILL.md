# 시스템 모니터링 요원 — job-watch

## 하는 일
지켜볼 작업표의 작업마다 기록 파일을 찾아 마지막 기록 시각을 읽고, "몇 분마다" 돌아야 하는 작업이 그 배수보다 오래 조용하면 멈춤, 실패로 볼 말이 있으면 실패로 판정해 상태표와 알림 문안을 만든다.
결과는 AI가 느낌으로 매기는 것이 아니라 스크립트가 표(규칙)대로 세고 판정한다. 기준을 바꾸고 싶으면 스크립트가 아니라 규칙 표를 고친다.

## 필요한 것
- 필요한 프로그램: Python 3 (없으면 멈추고 무엇이 없는지 한 줄로 알린다)
- 키·로그인: 없음. 이 스킬은 아무 서비스에도 접속하지 않고 파일만 읽고 쓴다.

## 작업 폴더
- 작업 폴더는 지금 작업 폴더 안의 `작업-감시` 로 한다. 처음 실행하면 연습 자료와 규칙 표가 그 안에 한 번만 복사된다. 이미 있는 파일은 덮어쓰지 않는다.
- 스킬 폴더의 `samples` 는 원본이다. 고치지 않는다. 사용자가 고치는 것은 작업 폴더의 복사본이다.

## 순서
1. 먼저 한 가지를 묻는다: "연습 자료로 먼저 한 번 볼까요, 바로 내 자료로 할까요?" 연습 결과를 사용자의 실제 결과처럼 말하지 않는다.
2. 내 자료로 할 때: 기록 파일(.txt/.log)은 `01_기록` 에 둔다. 기록 한 줄은 `2026-10-05 18:30` 처럼 날짜·시각으로 시작해야 읽는다. 내 자동화가 만든 기록 파일을 복사해 오거나 위치를 알려 준다.
   내 자료의 칸 이름이 다르면 사용자에게 어느 칸이 무엇인지 한 번 확인하고, 원본은 고치지 않고 칸 이름을 맞춘 사본을 쓴다.
3. 규칙 표를 내 것으로 바꾼다. 무엇으로 바꿀지 모르면 사용자에게 묻는다(지어내지 않는다).
   - `02_규칙/지켜볼작업.csv` (작업 이름, 기록 파일, 몇 분마다, 담당자): 내 자동화 이름·기록 파일·주기·담당자로 바꾼다
   - `02_규칙/실패로볼말.csv` (실패로 볼 말, 이렇게 쓰였으면 괜찮음, 이유): 기록에서 실패로 볼 말
4. 이 스킬 폴더의 `scripts/run.py` 를 Python 으로 실행한다. 작업 폴더는 `--work <작업 폴더 경로>` 로 넘긴다 (선택 옵션: 기준 시각: `--now 지금`(이 컴퓨터 시각) 또는 `--now "2026-10-05 18:30"`. 비우면 연습 기록 안의 가장 늦은 시각을 쓴다. 실제로 쓸 때는 반드시 `--now 지금`). 이 줄은 AI용이다. 사용자에게 명령어를 보여 주지 않는다.
5. 결과를 열어 본다. 만들어지는 것: 결과/작업상태표.csv, 결과/보낼알림.txt, 결과/작업감시.html. HTML 화면은 허브 오른쪽 미리보기에 띄운다.
6. 스크립트가 알려 주는 확인 3가지를 읽고 그대로 전한다.
   - 지켜볼 작업을 빠짐없이 봤나
   - 기록 시각을 전부 읽었나
   - 문제 작업마다 알릴 담당자가 있나
   "확인 필요"가 있으면 이유를 쉬운 말로 알리고, 규칙 표를 어떻게 고치면 되는지 제안한 뒤 다시 돌린다. 표를 고치기 전에 사용자에게 먼저 묻는다.
7. 사람 눈으로 한 번 더 볼 것을 사용자에게 알린다(`references/검수표.md` 참고).
   - 멈춤으로 나온 작업이 정말 멈춘 건지(일부러 쉬는 날인지) 사용자에게 확인

## 지킬 것
- 연습 기록으로 나온 결과를 사용자의 실제 상태처럼 말하지 않는다. 실제 판정은 내 기록 파일과 `--now 지금` 으로만 한다. 기록 파일을 고치거나 지우지 않는다.
- 스크립트 코드는 고치지 않는다. 결과가 이상하면 규칙 표나 입력 자료를 본다.
- 사용자에게 보이는 안내와 만든 화면·문서에 터미널 명령어와 내 컴퓨터 폴더 경로를 넣지 않는다.
- 키·비밀번호·토큰을 묻거나 저장하지 않는다.

## 하지 않는 것
- 알림을 보내지 않는다(메신저·메일 연결 없음). 알림 문안은 파일로 만들어 사용자가 필요한 곳에 붙여 보낸다.

## 다 하면
결과 화면을 연 뒤 한 줄로 알린다: "OO를 만들었어요. 확인 3가지 중 N가지 통과, 확인 필요 M개." 그리고 질문 하나: "규칙 표에서 바꾸고 싶은 기준이 있나요?"
어떤 스킬을 썼는지(`job-watch`) 결과 끝에 한 줄로 남긴다.
