# 쇼핑몰 운영 관리자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 취소·환불·반품 주문을 뺐나 | 취소된 주문까지 세면 매출이 부풀려집니다 | `빼는상태.csv` 에 그 상태 이름을 한 줄 더합니다 |
| 상품별 합계가 전체 합계와 맞나 | 상품별 숫자를 더한 값이 전체와 다르면 어딘가 빠지거나 두 번 센 것입니다 | AI가 원인을 확인합니다 |
| 날짜가 빠진 날이 없나 | 주문이 없는 날이 표에서 사라지면 장사가 없던 날을 놓칩니다 | 주문 파일의 주문일시가 2026-10-07 처럼 적혀 있는지 봅니다 |

**사람 눈으로 한 번 더**

- [ ] 관리자 화면 숫자와 크게 다르지 않나 (취소 건만큼 차이 나는 건 정상)
- [ ] `기타` 로 빠진 상품이 너무 많지 않나
- [ ] 확인 필요가 0개인가
