# 원본 하나 -> 여러 채널 초안

이 스킬은 직접 글을 쓰지 않고, 원본을 한 번 정리한 뒤 채널별 스킬에 넘기는 길잡이다. 요청한 채널의 초안만 만든다.

## 채널별로 이어지는 스킬
| 만들 것 | 쓸 스킬 | 비고 |
|---|---|---|
| 카페 글 | `cafe-writer`(글만), `naver-cafe-writer`(그림 배치 + 검사), `cafe-column-cardnews`(칼럼 + 카드뉴스) | 올리기는 학생이 직접 |
| 숏폼 대본 | `youtube-shorts-script` | 이미 찍은 긴 영상에서 구간을 잘라 쓰려면 `longform-shorts` |
| 인스타 카드뉴스 | `cardnews-maker` | 1080x1350 이미지로 내보낸다 |
| 스레드 글 | `sns-writer` | |
| 썸네일·제목 | `youtube-thumbnail-ab` | |
| 링크에 유입 표시 | `utm-link` | 카페·인스타·카톡으로 나가는 링크 |
| 촬영본 편집 | `reels-style-router` 이하 릴스 편집 스킬, `video-studio` | |
어떤 스킬이 이 PC에 없으면 있는 것만으로 진행하고, 없는 것은 "이 채널은 아직 연결된 직원이 없다"고 알린다.

## 순서
1. 먼저 받는다: 원본(링크, 글, 대본), 읽을 사람, 내 브랜드·말투, 행동 유도 문구(CTA), 만들 채널. 링크가 유튜브면 자막을 받아 오고, 안 되면 학생이 대본을 붙여 주게 한다.
2. **원본 요약 한 장**을 만든다: 핵심 주장 한 줄, 근거·장면·인용할 말(출처 위치 표시), 쓰면 안 되는 주장, 행동 유도 문구, 채널별 목표 길이. 이 한 장을 모든 채널이 같이 본다.
3. 사실 확인: 숫자·날짜·최신 동향·성능·건강·법률·재무·정책처럼 영향이 큰 주장을 새로 더하거나 여러 출처를 합칠 때는 공식 출처로 확인한 것만 쓴다. 원본을 충실하게 요약하는 정도면 "원본에 따르면"으로 표시하고 새 사실은 더하지 않는다.
4. 학생의 말투로 쓰는 글이면 학생이 가진 글쓰기 기준(과거 글, 말투 메모)을 먼저 보고, 없으면 학생 글 2~3개를 요청해서 맞춘다. 말투 기준은 사실 근거가 아니다.
5. 채널별로 따로 쓴다(한 채널의 글을 길이만 줄여 다른 채널에 붙이지 않는다). 각 채널 스킬의 순서를 그대로 따른다.
6. 채널별 점검:
   - 카페: 제목, 구조, 이미지 위치, 행동 유도 문구, 링크 표시, 카페 규칙(홍보 허용 여부)
   - 카드뉴스: 장 수, 한 장에 한 가지 이야기, 읽히는 글자 크기, 내보내기 크기, 지어낸 그림·주장이 없는지
   - 숏폼: 첫 문장 후킹, 말하는 시간, 찍을 수 있는 장면인지, 자막, 쓰는 소재의 이용 허락
   - 스레드: 글자 수 제한, 가격·기간 같은 최신 정보, 이미지 준비
7. 초안이나 시험 단계에서 멈춘다. 학생이 결과를 보고 승인해야 한다.

## 하지 않는 것
- 게시, 발송, 예약 등록, 유료 이미지·영상 생성은 학생이 비용과 이유를 보고 승인하기 전에는 하지 않는다.
- 가짜 후기, 지어낸 수치, 자작 댓글을 만들지 않는다.
- 학생 화면에 터미널 명령과 내 컴퓨터 폴더 경로를 보이지 않는다.
- 한 채널 스킬이 윈도우에서 안 되는 부분이 있으면(자동 게시 도구 등) 초안까지만 만들고 "게시는 직접"이라고 알린다.
