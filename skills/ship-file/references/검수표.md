# 출고·배송 관리 담당자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 업로드 파일에 주소·전화 빠진 줄이 없나 | 빠지면 택배가 안 가거나 기사님이 연락을 못 합니다 | `보류조건.csv` 에 주소·전화 칸이 있는지 확인합니다 |
| 합칠 수 있는 주문을 합쳤나 | 같은 집에 박스가 두 번 가면 택배비가 두 번 나갑니다 | 이름이나 주소 글자가 조금 다른지 봅니다. 띄어쓰기 차이는 같은 것으로 봅니다 |
| 도서산간 표시가 빠지지 않았나 | 표시가 빠지면 추가 배송비를 우리가 떠안습니다 | `도서산간.csv` 의 우편번호 범위를 확인합니다 |

**사람 눈으로 한 번 더**

- [ ] 보류된 주문의 손님에게 연락했나
- [ ] 박스 크기가 실제 상품에 맞나
- [ ] 확인 필요가 0개인가
