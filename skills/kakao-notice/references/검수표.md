# 카카오톡 오픈채팅방 관리자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 방마다 하루 최대를 지켰나 | 한 방에 너무 많이 보내면 손님이 알림을 끄거나 나갑니다 | `방별규칙.csv` 의 하루 최대를 확인합니다 |
| 밤 시간에 잡힌 게 없나 | 자는 시간 알림은 실례라 방을 나가는 사람이 생깁니다 | `보내면안되는시간.csv` 를 확인합니다 |
| 링크에 꼬리표가 붙었나 | 꼬리표가 없으면 손님이 어느 방에서 들어왔는지 알 수 없습니다 | 프로그램이 붙입니다. 걸리면 링크가 http 로 시작하는지 확인합니다 |

- [ ] 날짜·시간·가격이 맞나
