# AI·도구 설명형 릴스 편집

참고한 것은 특정 크리에이터의 영상 문법이며, 그 영상을 그대로 따라 만들거나 그 사람의 얼굴·이름·소재를 가져다 쓰지 않는다.

## 준비
- 공통 준비와 설치는 `reels-style-router/SKILL.md`의 "공통 준비"를 따른다.
- **화면 녹화가 핵심 재료다.** 소개할 도구의 실제 화면을 학생이 직접 녹화하거나, 학생 허락을 받고 AI가 화면 캡처를 만든다. 계정 이름, 이메일, 결제 정보, 고객 데이터가 보이는 화면은 가리거나 쓰지 않는다. 학생 계정의 비밀 정보가 보이면 쓰지 않고 알린다.

## 화면 규칙
- 말하는 화면을 기본 자리로 둔다.
- 도구 이름이 나오면 로고만 띄우지 말고 실제 화면, 대시보드, 결과 화면을 보여 준다.
- 흐름: 도구 소개 -> 기능 화면 -> 실제 효과나 결과 -> 다음 단계.
- 짧은 자막, 핵심어만 색 강조. 화면 변화는 1.5~2.3초 간격을 기준으로 설명 길이에 맞춘다.
- 비교·순위는 같은 화면 안 카드나 순서대로 바뀌는 화면으로 정리한다.
- 끝 호출 문구는 질문형 문장 + 프로필·채널 카드로.
- 같은 화면 녹화나 보조 영상을 반복해서 쓰지 않는다.
- 없는 기능을 있는 것처럼 보여 주지 않는다. 결과는 실제로 돌려 본 것만 쓴다.

## 순서
1. 받아쓴 자막에서 도구명, 기능, 입력, 출력, 결과, 비교, 끝 호출 문구를 표시한다.
2. `edit-plan.json`을 만든다. 칸: `start`, `end`, `dialogue`, `scene_type`, `tool`, `asset_query`, `caption_emphasis`, `transition`. (`router.py --style tool-demo`이 초안을 만든다.)
3. 렌더 후 대표 화면을 학생에게 보여 준다.
