# 블로그 마케터 — blog-checker

## 하는 일
원고 파일들을 읽어 제목에 키워드가 있는지, 본문 키워드 횟수·최소 글자 수·소제목 개수를 세고, 쓰면 안 되는 말을 찾아 통과한 글은 정리본(제목·본문 복사 화면)으로, 못 맞춘 글은 보류와 이유로 나눈다.
결과는 AI가 느낌으로 매기는 것이 아니라 스크립트가 표(규칙)대로 세고 판정한다. 기준을 바꾸고 싶으면 스크립트가 아니라 규칙 표를 고친다.

## 필요한 것
- 필요한 프로그램: Python 3 (없으면 멈추고 무엇이 없는지 한 줄로 알린다)
- 키·로그인: 없음. 이 스킬은 아무 서비스에도 접속하지 않고 파일만 읽고 쓴다.

## 작업 폴더
- 작업 폴더는 지금 작업 폴더 안의 `블로그-점검` 로 한다. 처음 실행하면 연습 자료와 규칙 표가 그 안에 한 번만 복사된다. 이미 있는 파일은 덮어쓰지 않는다.
- 스킬 폴더의 `samples` 는 원본이다. 고치지 않는다. 사용자가 고치는 것은 작업 폴더의 복사본이다.

## 순서
1. 먼저 한 가지를 묻는다: "연습 자료로 먼저 한 번 볼까요, 바로 내 자료로 할까요?" 연습 결과를 사용자의 실제 결과처럼 말하지 않는다.
2. 내 자료로 할 때: 원고는 표(CSV: 상품, 제목, 본문) 또는 메모장(.txt, 첫 줄이 제목, 소제목 줄 앞에 ## )으로 `01_원고` 폴더에 둔다. 연습 원고를 점검에서 빼려면 `01_원고/연습` 폴더로 옮긴다.
   내 자료의 칸 이름이 다르면 사용자에게 어느 칸이 무엇인지 한 번 확인하고, 원본은 고치지 않고 칸 이름을 맞춘 사본을 쓴다.
3. 규칙 표를 내 것으로 바꾼다. 무엇으로 바꿀지 모르면 사용자에게 묻는다(지어내지 않는다).
   - `02_규칙/키워드.csv` (상품, 메인 키워드, 이유): 상품마다 손님이 검색하는 말 하나
   - `02_규칙/글규칙.csv` (규칙, 값, 이유): 제목에 키워드, 본문 키워드 횟수 범위, 최소 글자 수, 소제목 최소 개수
   - `02_규칙/쓰면안되는말.csv` (쓰면 안 되는 말, 바꿔 쓸 말, 이유): 과장 광고로 걸리기 쉬운 말. 식품·화장품·건강 상품은 업종에 맞게 더한다
4. 이 스킬 폴더의 `scripts/run.py` 를 Python 으로 실행한다. 작업 폴더는 `--work <작업 폴더 경로>` 로 넘긴다. 이 줄은 AI용이다. 사용자에게 명령어를 보여 주지 않는다.
5. 결과를 열어 본다. 만들어지는 것: 결과/블로그_점검.html(점검 화면, 제목·본문 복사 버튼), 결과/점검표.csv, 결과/정리본/(통과한 글 메모장). HTML 화면은 허브 오른쪽 미리보기에 띄운다.
6. 스크립트가 알려 주는 확인 3가지를 읽고 그대로 전한다.
   - 준비된 글은 모두 키워드 기준을 지켰나
   - 위험 표현이 없나
   - 같은 제목이 겹치지 않나
   "확인 필요"가 있으면 이유를 쉬운 말로 알리고, 규칙 표를 어떻게 고치면 되는지 제안한 뒤 다시 돌린다. 표를 고치기 전에 사용자에게 먼저 묻는다.
7. 사람 눈으로 한 번 더 볼 것을 사용자에게 알린다(`references/검수표.md` 참고).
   - 첫 문단만 읽어도 끝까지 읽고 싶어지나
   - 상품 설명이 사실과 맞나(용량·재료·가격)

## 지킬 것
- 결과가 이상하면 스크립트가 아니라 규칙 표를 고친다. 보류된 글은 정리본을 만들지 않는다. 원고 내용은 사용자 허락 없이 고쳐 쓰지 않고, 보류 이유를 알려 주고 고칠지 먼저 묻는다.
- 스크립트 코드는 고치지 않는다. 결과가 이상하면 규칙 표나 입력 자료를 본다.
- 사용자에게 보이는 안내와 만든 화면·문서에 터미널 명령어와 내 컴퓨터 폴더 경로를 넣지 않는다.
- 키·비밀번호·토큰을 묻거나 저장하지 않는다.

## 하지 않는 것
- 블로그에 올리는 일은 하지 않는다. 정리본을 붙여넣기까지만 돕고, 네이버 편집창에 넣고 임시저장까지 하려면 blog-marketer 를 쓴다. 발행 버튼은 사용자가 누른다. 네이버 아이디·비밀번호는 받지 않는다.

## 다 하면
결과 화면을 연 뒤 한 줄로 알린다: "OO를 만들었어요. 확인 3가지 중 N가지 통과, 확인 필요 M개." 그리고 질문 하나: "규칙 표에서 바꾸고 싶은 기준이 있나요?"
어떤 스킬을 썼는지(`blog-checker`) 결과 끝에 한 줄로 남긴다.
