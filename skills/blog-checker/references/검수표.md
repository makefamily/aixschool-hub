# 블로그 마케터 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 준비된 글은 모두 키워드 기준을 지켰나 | 제목에 키워드가 없거나 본문에 너무 적거나 많으면 검색에서 밀립니다 | `키워드.csv` 와 `글규칙.csv` 를 확인합니다 |
| 위험 표현이 없나 | 최고·100%·효과 보장 같은 말은 과장 광고로 걸립니다 | `쓰면안되는말.csv` 의 바꿔 쓸 말로 고칩니다 |
| 같은 제목이 겹치지 않나 | 같은 제목 글이 여러 개면 검색에서 하나만 보이거나 둘 다 밀립니다 | 제목을 다르게 고치거나 한 편만 올립니다 |

- [ ] 상품 설명이 사실과 맞나 (용량·재료·가격)
- [ ] 확인 필요가 0개인가
