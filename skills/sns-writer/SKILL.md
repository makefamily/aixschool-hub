# SNS 마케터

실제로 매일 돌리는 스레드 운영 흐름을 그대로 옮겼다: 내 자료 읽기 → 초안 → 글자 수·형식 검사 → 사람 확인 → 게시 → 링크 기록.
게시에 필요한 건 각자의 Threads 토큰 하나뿐이다. 없으면 이 문서의 '연결이 없을 때'대로 안내한다.

## 1. 먼저 읽을 것
- 허브 폴더의 내 자료: `my/about.md`(나와 내 일), `my/writing/`(내가 쓴 글), `my/thinking.md`(내 생각). 이 파일들의 위치는 AI 직원표 아래 '내 자료' 절에 있다.
- 내 자료가 비어 있으면 글은 쓰되, 다 하고 끝에 한 줄: "my/writing 에 내가 쓴 글 3편을 넣으면 말투가 훨씬 내 글처럼 돼요."
- 오늘(또는 최근) 한 일 기록이나 메모. 사용자가 말로 준 내용도 기록이다. 아무것도 없으면 한 가지만 묻는다: "오늘 한 일이나 쓰고 싶은 이야기를 한두 줄로 알려 주세요."

## 2. 초안
1. 내 예전 글에서 이야기 순서와 줄 수 배분만 뽑는다. 문장은 베끼지 않는다.
2. 기록에서 읽을 이유가 있는 사건을 고른다. 실제로 한 일과 실제 결과만. 개수를 채우려고 없는 일을 만들지 않는다.
3. 쓴다.
   - 첫 두 줄 안에서 "내 얘기다" 또는 "이게 뭐지" 하게 한다.
   - 스레드는 한 편 500자 이내(내 규칙에 더 짧은 기준이 있으면 그것). 인스타 캡션은 첫 줄에 핵심.
   - 이모지, 본문 안 링크, 사람 이름, 연락처, 내 컴퓨터 폴더 경로를 쓰지 않는다.
   - 마지막 줄 행동 유도는 댓글 요구가 아니라 프로필 링크 한 곳으로 보낸다.
4. 작업 폴더에 `sns-초안-1.md` … 로 저장. 파일 밑에 글자 수, 고른 이유, 근거를 적는다.

## 3. 검사
- 글자 수를 실제로 센다(공백 포함, 500자 이하).
- 지어낸 숫자·후기·성과가 없는지, 사람·방 이름이 없는지 다시 본다.

## 4. 게시 (스레드)
1. 사용자에게 올릴 글을 그대로 보여 주고 묻는다: "이대로 스레드에 올릴까요?" 확인 없이는 절대 올리지 않는다.
2. 확인을 받으면 이 스킬 폴더의 `scripts/threads-post.mjs`를 Node로 실행한다.
   - 먼저 `check`로 연결을 확인한다.
   - 게시: `post <초안파일> --yes`. 본문만 들어 있는 파일을 따로 만들어 넘긴다(글자 수·근거 메모 제외).
3. 결과로 나온 게시 링크를 사용자에게 주고, 작업 폴더 `posted.json`에 기록된 것을 확인한다.
4. 토큰이 60일 가까이 됐으면 `refresh`로 연장할지 묻는다.
- 인스타그램 게시는 아직 이 흐름에 없다. 인스타는 캡션 파일까지 만들고, 올리는 건 사용자가 한다고 알린다.

## 연결이 없을 때
`check`가 "연결 필요"를 말하면 멈추고 이렇게 안내한다(키를 대화에 붙여 넣으라고 하지 않는다).
1. "스레드에 자동으로 올리려면 Threads 토큰이 한 번 필요해요. 10분쯤 걸려요."
2. 허브 설정 › 연결 › Threads 카드를 열게 하고, 거기 적힌 순서(메타 개발자 앱 만들기 → Threads 사용 사례 → 권한 threads_basic, threads_content_publish → 토큰 만들기)를 함께 따라간다. 화면이 바뀌어 있으면 공식 문서(https://developers.facebook.com/docs/threads/get-started)를 열어 지금 화면 기준으로 안내한다.
3. 토큰은 허브 연결 화면의 칸에 사용자가 직접 넣는다. 대화에 붙여 넣으면 가리고 연결 화면에 다시 넣자고 말한다.
4. 넣었다고 하면 `check`로 확인한 뒤 게시로 돌아간다.

## 지킬 것
- 확인 없이 게시·예약·댓글·팔로우·메시지 발송을 하지 않는다.
- 키·토큰 값을 출력하거나 파일에 쓰지 않는다(스크립트가 금고에서 직접 꺼낸다).
- 고객·수강생이 특정되는 이야기는 쓰지 않는다.
- 사용자에게 보이는 안내에 터미널 명령어를 넣지 않는다. 실행은 AI가 한다.

## 다 하면
"초안 N개를 만들었고 (게시했다면) 여기 올렸어요: 링크" 한 줄, 질문 하나: "다음 글은 어떤 이야기로 쓸까요?"
