# 메모지형 릴스 (새 자료 + 모션그래픽 + 4K)

호출 이름은 **메모지형**이다. 완성물은 학생이 확인한 MP4와 고칠 수 있는 소스다. 계획 파일만 만들고 끝내지 않는다.

## 재사용하는 것, 매번 새로 만드는 것
- 재사용: 출력 비율, 자료 상자와 자막 위치, 글꼴, 렌더·검사 도구.
- 새로 제작: 이번 영상의 말을 설명하는 그림·도형·화면·문구·움직임. 이전 영상에 쓴 자료를 가져다 다시 배치하지 않는다. 같은 틀에서 색과 문구만 바꾼 화면을 여러 개 만드는 것도 목적에 맞지 않는다.
- 위쪽: 말을 이해시키는 부연 자료와 짧은 안내. 아래 자막을 줄여서 다시 띄우는 곳이 아니다.
- 아래쪽: 실제 말과 시간이 맞는 자막. 요약이나 카피로 바꾸지 않는다.
- 모션그래픽이 우선이다(가림막이 걷히는 효과, 도형·글자 움직임, 대상에 붙는 설명선, 고치기 전후 비교). 웹사이트 화면은 실제 화면을 설명할 때만 새로 녹화해서 쓴다.
- 학생이 새로 녹화한 화면 자료에는 커서를 따라 부드럽게 확대·이동하는 효과를 쓸 수 있다(선택).
- "출처", "제작용" 같은 배지는 화면에 넣지 않는다. 실제 자료인지 새로 만든 설명용 그림인지는 계획 파일에만 기록하고, 실제 성과·배포 서비스라고 주장하지 않는다.
- 한 영상 안에서 같은 보조 영상 파일을 반복해서 쓰지 않는다. 이름이나 크기만 바꿔 중복을 피했다고 하지 않는다.

## 준비
공통 준비(ffmpeg, Node 22, HyperFrames, 받아쓰기, 글꼴)는 `reels-style-router/SKILL.md`의 "공통 준비"를 따른다. 이 스킬의 상세 절차와 계획 파일 항목은 `references/production.md`, 움직임 선택은 `references/motion-design.md`, 크기·배치 기준은 `references/style-profile.json`이다. 글꼴 3종(OFL)은 `assets/fonts/`에 들어 있고 GSAP은 고정 버전을 받아 해시로 확인한다.

## 크기와 음성 규칙
- 출력은 **2160x3840, 30fps**. 배치는 1080x1920 설계 좌표를 두 축 같은 비율로 2배 한다. 새 글자·그림은 4K에서 직접 그린다. 1080p 완성본을 늘려서 4K라고 하지 않는다.
- 이 스킬의 음성은 **이미 말 사이를 다듬어 둔 마스터**를 그대로 쓴다. 순서·간격·길이·속도를 바꾸지 않는다. 다듬기 전 촬영본만 있다면 먼저 `video-studio`의 편집 절차로 음성을 정리해 학생 확인을 받은 뒤 시작한다. 확인하지 못했으면 "미확인"으로 남기고 임의로 다시 자르지 않는다.
- 길이, 자막 수, 의미 구간 수, 자료 개수는 입력에서 정한다. 예전 영상의 길이나 칸 수를 고정하지 않는다.

## 순서 (AI가 실행. 학생에게는 단계 이름만 말한다)
1. 원본, 고정 음성, 실제 받아쓴 자막을 확보한다. 받아쓰기만으로 자막 검수와 창작이 끝났다고 하지 않는다. 학생에게 자막 문구를 확인받는다.
2. 의존성 확인(`scripts/resolve_dependencies.py`) -> 준비(`scripts/prepare.py`: 입력 검사, 대표 화면, 작업 소개 파일 `BRIEF.md`, `edit-manifest.json` 생성).
3. 전체 자막을 읽고 뜻 단위로 나눈 뒤, **이번 영상만의** 자료 설계표를 만든다(연결 자막, 부연 목적, 디자인, 움직임, 등장·퇴장 시점, 새로 만든 소스).
4. 자료를 직접 만든다. SVG/HTML/GSAP 등 고칠 수 있는 소스로 만들고, 필요하면 독립 영상으로 먼저 렌더한다. 그림 이미지가 필요하면 학생 구독의 이미지 생성 도구(유료 호출은 먼저 허락)를 쓴다. 이름 있는 효과는 `hyperframes-registry`를 먼저 찾는다.
5. `edit-manifest.json`을 정본으로 본편·자료·상단 문구·하단 자막을 연결한다(`scripts/build_composition.py`). 굽는 자막과 SRT 파일은 같은 자막 데이터에서 만든다.
6. `scripts/validate_plan.py`로 계획을 검사하고, 대표 구간을 실제 출력 크기로 렌더해 작은 화면에서도 대상과 동작이 읽히는지 본다. 그 뒤 전체를 렌더한다.
7. 고정 음성을 최종 영상에 그대로 복사하고 길이와 음성 해시를 검사한다(`scripts/verify_delivery.py`). 자동 배경음악·효과음은 넣지 않는다.
8. 검사: 실제 출력 해상도, 자료 중복, 전체 디코딩, 전 구간 대표 화면. 직접 듣기, 입 모양, 움직임 속도는 기계 검사와 따로 기록한다. 확인하지 못한 것을 통과라고 쓰지 않는다.
9. 최종 MP4와 소스 위치를 학생에게 알린다. 올리거나 게시하는 일은 하지 않는다.

## "애프터이펙트 효과"라는 말
기본 경로는 HyperFrames에서 구현하는 비슷한 시각 효과다. Adobe After Effects를 실행했다거나 `.aep` 파일을 만들었다고 말하지 않는다.
