# 나가는 링크에 UTM 붙이기

## 왜 하나
추적 표시 없이 나간 링크로 들어온 사람은 분석 도구(GA4 등)에서 "직접 방문" 한 덩어리로 묻힌다. 어느 채널이 효과가 있었는지 알 수 없게 된다. 링크 뒤에 표시를 붙이면 채널별로 갈라서 볼 수 있다.

## 먼저 물어볼 것
- 링크의 도메인(내 사이트 주소)과, 그 사이트에 분석 도구(GA4 등)가 붙어 있는지. **분석이 안 붙은 곳은 붙여도 아무것도 안 잡힌다.** 노션·구글폼·남의 사이트가 그렇다. 이 경우 "붙일 필요 없다"고 말하고 멈춘다. 분석 도구가 있는지 모르면 학생에게 확인을 부탁하고, AI가 사이트 소스에서 분석 코드가 있는지 읽어 본다.
- 어느 채널에 뿌릴지(인스타 프로필, 인스타 글, 스토리, DM, 스레드, 카톡, 단톡방, 문자, 이메일, 뉴스레터, 카페, 블로그, 유튜브 설명, 광고)
- 어떤 건인지 이름(캠페인)

## 필요한 것
파이썬만 있으면 된다(추가 설치·키·계정 연결 없음). 맥은 `python3`, 윈도우는 `python`으로 AI가 알아서 실행한다. 학생에게 명령을 보여 주지 않는다.

## 순서
1. 링크, 내 도메인, 채널, 캠페인 이름을 정한다. 캠페인 이름은 `YYMMDD-이름`(예: `261201-event`)으로 고정한다. 날짜를 앞에 두면 회차별 비교가 쉽다. 같은 건이면 채널이 달라도 캠페인 이름은 같게 둔다.
2. `scripts/utm.py`로 만든다. 채널 하나면 `--preset`, 여러 채널이면 `--all`로 한 번에 뽑는다. 프리셋에 없는 채널은 `--source`, `--medium`을 직접 준다(소문자·하이픈).
3. 결과를 `링크표.md`(채널 | 링크)로 저장하고, 학생이 복사해 쓸 수 있게 채널별로 보여 준다.
4. 링크를 눌러 열리는지 한 번 확인한다(붙인 표시 때문에 깨지지 않았는지).

## 붙이지 않는 경우 (도구가 알아서 판단한다. 결과를 그대로 믿는다)
- 내 분석이 없는 도메인
- 링크에 이미 `utm_source`가 있는 경우: 손으로 정해 둔 표시를 덮지 않는다.

## 주의
- 이미 뿌린 링크는 소급되지 않는다. 지금 바꿀 수 있는 곳(프로필 링크 등)만 바꾼다.
- 문자(SMS)는 링크가 길어지면 장문 문자로 바뀌어 요금이 올라갈 수 있다. 문자에 쓸 링크는 길이를 먼저 확인한다.
- 링크를 줄이는 서비스는 쓰지 않는다. 줄인 주소는 스팸으로 걸러지기도 한다.
- 대소문자를 섞지 않는다(도구가 소문자로 맞춘다).
- 결과 확인: 분석 도구의 "획득/트래픽" 보고서에서 캠페인·소스/매체로 본다. 분석 도구 화면은 학생이 직접 연다.
