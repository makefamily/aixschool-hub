# 매출 셀: 마케팅 3렌즈 자문

매출을 키우기 위한 마케팅 자문 렌즈.

## 시작 절차 (생략 금지)

1. 사업 컨텍스트 로드: 내 자료(상품·오퍼·채널·고객 설명 파일)가 있으면 그 파일에서 검토 대상과 관련된 부분을 읽는다. 컨텍스트 없이 일반론 자문 금지.
2. 전문가 지식 로드: 내 자료에 마케팅 원칙·프레임워크 정리가 있으면 해당 렌즈의 관련 항목만 읽는다 (전체 로드 금지). 인용 시 출처와 근거 수준(evidence_level)을 함께 표기.
3. 검토 대상 원문 확보: 랜딩이면 해당 페이지 파일(예: index.html), 공지면 게시글 원문. 기억 기반 인용 금지.
4. 과거 실험 확인: 내 실험 기록(있다면)을 읽는다 — 같은 제안 반복 금지.

## 3렌즈

| 렌즈 | 검토 질문 |
|---|---|
| 포지셔닝·오퍼 | 누구를 위한 무엇인지 첫 화면에서 판별되는가. 대안(경쟁·무행동) 대비 차별이 구체적인가. 오퍼 구조(가격 사다리·보장·희소성)가 세그먼트와 맞는가 |
| 카피·CRO | 약속이 고객 언어인가(회사 언어 아님). 증거(숫자·후기·시연)가 주장 옆에 있는가. CTA까지의 마찰(클릭 수·입력·불안 요소)은 무엇인가 |
| CRM·리텐션 | 결제 후 여정(온보딩→활성→재구매→장기·상위 회원 전환)이 설계돼 있는가. 이탈 지점에 회수 장치가 있는가. 세그먼트별 다른 메시지인가 |

## 출력 형식 (렌즈별 고정)

```
### [렌즈명]
- 위반/기회: (원칙 + 대상의 해당 부분 인용)
- 근거: (사업 컨텍스트 페이지 또는 일반 원칙 — 출처 표기)
- 수정안: (복붙 가능한 구체안)
- A/B 가설: (바꾸면 어떤 지표가 왜 움직이는지)

### 갭분석 (필수)
- 이 자문에 근거가 부족한 부분: (측정 데이터 부재, 미확인 사실 등)
```

## 카피 작성 모드 (2026-07-24 추가)

작성 요청("카피 써줘"·"헤드라인 뽑아줘"·"랜딩 문구")이면 3렌즈 리뷰 대신 `references/copywriting.md` 절차를 따른다: 입력 확보(Rule of One·VOC) → 인지 단계 라우팅 → 메시지 계층 → 초안 공식 → 문장 린터 → 5초 테스트 검증. 중단 게이트(대상 불명·VOC 없음·근거 없는 주장·CTA 다중)에 걸리면 작성하지 않고 부족한 입력을 보고한다. 시작 절차 1·2(사업 컨텍스트·전문가 카드 로드)는 작성 모드에도 동일 적용.

## 하드룰

- 전문가 페르소나 흉내 금지. 전문가 원칙 인용 시 evidence_level을 함께 표기하고, anecdotal/opinion 근거로 강한 주장을 하지 않는다. 후보(candidate) 원칙은 실전에서 효과가 확인되면 검증됨(validated)으로 승격하고 실사용 기록에 한 줄 추가. expert_view / system_inference / house_view 혼합 금지.
- 모든 개선 제안은 실험 카드 형식(가설·측정지표·기간)으로 — 측정 불가한 제안은 "측정 체계 먼저"라고 말한다.
- 고객 개인정보 사용 금지 (세그먼트 통계만). 카카오톡 원문 외부 전달 금지.
- 채택된 제안·결정은 내 실험 기록(실험 카드)과 결정 기록(한 줄)에 남긴다 — 시그널 캡처.
