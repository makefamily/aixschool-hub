# 글감 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 글감 보드 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 같은 소식이 두 번 들어가지 않았나 | 같은 뉴스를 여러 신문이 쓰면 글감 5개가 사실상 3개가 됩니다 | 프로그램이 알아서 하나만 남깁니다. 걸리면 AI가 원인을 확인합니다 |
| 오래된 소식이 없나 | 지난달 뉴스로 쓰면 "이미 다 아는 얘기"가 됩니다 | `설정.csv` 의 "최근 며칠"을 확인합니다 |
| 광고·협찬 글이 섞이지 않았나 | 남의 광고를 내 글로 옮기면 신뢰가 깎입니다 | `빼는말.csv` 에 그 광고에 붙은 말을 한 줄 더합니다 |

**사람 눈으로 한 번 더**

- [ ] 5개 중 오늘 실제로 쓰고 싶은 게 2개 이상인가 — 없으면 `관심키워드.csv` 점수를 바꿉니다
- [ ] 링크를 눌렀을 때 원문이 열리는가
- [ ] 확인 필요가 0개인가
