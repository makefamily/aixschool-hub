# 콘텐츠 에디터 — news-digest

## 하는 일
소식 목록에서 같은 소식·7일 넘은 소식·광고 글을 빼고, 관심 키워드가 든 소식에 점수를 매겨 높은 순으로 글감 보드를 만든다. 모을곳 표에 적은 공개 소식 주소에서 진짜 소식을 모으는 선택 기능이 있다.
결과는 AI가 느낌으로 매기는 것이 아니라 스크립트가 표(규칙)대로 세고 판정한다. 기준을 바꾸고 싶으면 스크립트가 아니라 규칙 표를 고친다.

## 필요한 것
- 필요한 프로그램: Python 3 (없으면 멈추고 무엇이 없는지 한 줄로 알린다)
- 키·로그인: 없음. 이 스킬은 아무 서비스에도 접속하지 않고 파일만 읽고 쓴다.

## 작업 폴더
- 작업 폴더는 지금 작업 폴더 안의 `글감-보드` 로 한다. 처음 실행하면 연습 자료와 규칙 표가 그 안에 한 번만 복사된다. 이미 있는 파일은 덮어쓰지 않는다.
- 스킬 폴더의 `samples` 는 원본이다. 고치지 않는다. 사용자가 고치는 것은 작업 폴더의 복사본이다.

## 순서
1. 먼저 한 가지를 묻는다: "연습 자료로 먼저 한 번 볼까요, 바로 내 자료로 할까요?" 연습 결과를 사용자의 실제 결과처럼 말하지 않는다.
2. 내 자료로 할 때: 소식은 표(CSV)로 `01_소식/소식_샘플.csv` 에 둔다. 칸: 제목, 출처, 날짜, 요약, 링크. 진짜 소식 모으기는 계정·키 없이 공개 주소만 읽는다.
   내 자료의 칸 이름이 다르면 사용자에게 어느 칸이 무엇인지 한 번 확인하고, 원본은 고치지 않고 칸 이름을 맞춘 사본을 쓴다.
3. 규칙 표를 내 것으로 바꾼다. 무엇으로 바꿀지 모르면 사용자에게 묻는다(지어내지 않는다).
   - `02_규칙/관심키워드.csv` (키워드, 점수, 이유): 내 업종 키워드 3~5개
   - `02_규칙/모을곳.csv` (이름, 종류, 주소나 검색어): 진짜 소식을 모을 곳(구글 뉴스 검색어, 유튜브·블로그 주소)
   - `02_규칙/빼는말.csv` (빼는말, 이유): 광고·협찬에 붙는 말
   - `02_규칙/설정.csv` (항목, 값, 설명): 최근 며칠, 고를 개수 등
4. 이 스킬 폴더의 `scripts/run.py` 를 Python 으로 실행한다. 작업 폴더는 `--work <작업 폴더 경로>` 로 넘긴다 (선택 옵션: 진짜 소식 모으기: `--live`(공개 주소만 읽는다, 사용자에게 한 줄 알리고 실행). 다른 소식 파일: `--input <CSV>`). 이 줄은 AI용이다. 사용자에게 명령어를 보여 주지 않는다.
5. 결과를 열어 본다. 만들어지는 것: 결과/오늘의글감.html, 결과/글감목록.csv. HTML 화면은 허브 오른쪽 미리보기에 띄운다.
6. 스크립트가 알려 주는 확인 3가지를 읽고 그대로 전한다.
   - 같은 소식이 두 번 들어가지 않았나
   - 7일 넘은 소식이 없나
   - 광고·협찬 글이 섞이지 않았나
   "확인 필요"가 있으면 이유를 쉬운 말로 알리고, 규칙 표를 어떻게 고치면 되는지 제안한 뒤 다시 돌린다. 표를 고치기 전에 사용자에게 먼저 묻는다.
7. 사람 눈으로 한 번 더 볼 것을 사용자에게 알린다(`references/검수표.md` 참고).
   - 고른 글감이 내 손님에게 실제로 쓸모 있나

## 지킬 것
- 소식의 사실·숫자는 원문 링크 기준이다. 요약을 AI가 더 키우거나 지어내지 않는다. 연습 소식(샘플)을 오늘의 실제 소식처럼 말하지 않는다.
- 스크립트 코드는 고치지 않는다. 결과가 이상하면 규칙 표나 입력 자료를 본다.
- 사용자에게 보이는 안내와 만든 화면·문서에 터미널 명령어와 내 컴퓨터 폴더 경로를 넣지 않는다.
- 키·비밀번호·토큰을 묻거나 저장하지 않는다.

## 하지 않는 것
- 글을 쓰거나 올리지 않는다. 글감까지만 만든다.

## 다 하면
결과 화면을 연 뒤 한 줄로 알린다: "OO를 만들었어요. 확인 3가지 중 N가지 통과, 확인 필요 M개." 그리고 질문 하나: "규칙 표에서 바꾸고 싶은 기준이 있나요?"
