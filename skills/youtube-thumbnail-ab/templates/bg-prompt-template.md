# 배경 이미지 요청 틀 (AI용, 학생에게 그대로 보여 주지 않는다)

빈칸 {} 을 이번 영상에 맞게 채워서 이미지 생성 도구에 준다. 3장을 한 번에 만든다.

16:9 유튜브 썸네일 배경 이미지 3장(1536x864 이상)을 만든다. 사진처럼 보이는 실사 느낌, 대비가 뚜렷한 조명.
이미지 안에는 글자를 넣지 않는다. 아래 22%는 나중에 카피를 올릴 자리라 어둡거나 단순하게 비워 둔다.

공통 구도(3장 모두):
- 왼쪽 3분의 1: {시청자가 알아볼 큰 대상 1 - 예: 내 서비스 화면, 도구 화면, 제품}. 화면 높이의 65~70%, 잘리지 않게.
- 가운데 3분의 1: {인물}. 얼굴이 세로 중앙선에 오게. 평범한 실사 인물, 빛나는 눈·회로 무늬 같은 'AI 효과' 금지.
  학생 본인 얼굴이 필요하면 본인이 제공한 실제 사진만 쓴다(얼굴을 새로 만들어 쓰지 않는다).
- 오른쪽 3분의 1: {시청자가 겪는 문제나 비교 대상 - 예: 쌓인 서류, 깨진 화면}. 55~60%.

장면:
1) a.png - {감정 1: 예 통쾌함}. 인물 동작 {팔짱}. 배경 {어두운 남색 스튜디오}.
2) b.png - {감정 2: 예 호기심}. 인물 동작 {노트북을 가슴 높이로 들고 있음}. 배경 {짙은 회색 스튜디오}.
3) c.png - {감정 3: 예 찔림}. 인물 동작 {손가락으로 가리킴}. 배경 {밝은 파랑}.

저장한 뒤 세 파일의 경로를 알려 준다. 다른 파일은 건드리지 않는다.
