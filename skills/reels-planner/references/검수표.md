# 릴스 PD 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 장면마다 읽을 시간이 충분한가 | 자막이 너무 빨리 지나가면 끝까지 못 읽고 넘깁니다 | `장면길이.csv` 의 1초에 읽는 글자 수·최대 초를 확인합니다 |
| 캡션이 길이 안인가 | 첫 줄이 길면 잘려서 무슨 말인지 안 보입니다 | 릴스 제목(첫 줄)을 줄이거나 `캡션규칙.csv` 를 확인합니다 |
| 해시태그 개수가 기준 안인가 | 인스타가 받는 개수보다 많으면 뒤의 태그는 안 붙습니다 | `해시태그.csv` 에서 주제별 태그를 줄입니다 |

**사람 눈으로 한 번 더**

- [ ] 자막 문장이 내 말투와 맞나
- [ ] 첫 줄만 보고도 영상을 보고 싶어지나
- [ ] 확인 필요가 0개인가
