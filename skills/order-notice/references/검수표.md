# 검수표 — 나가도 되는 안내문인가

안내문이 만들어졌으면 **한 건씩** 봅니다. 프로그램이 자동으로도 봐 주지만,
눈으로 한 번 보는 게 마지막 관문입니다.

## 안내문 한 건마다

- [ ] **상품에 맞는 자료 링크**가 붙었나
      전자책 주문에 자료 링크가 붙어 있지 않은가
- [ ] **주문에 없는 말**을 지어내지 않았나
      주문서에 없는 배송일, 할인, 기간이 들어가 있지 않은가
- [ ] **넣으면 안 되는 말**이 들어갔나
      규칙의 `넣으면안되는말` 칸에 적어둔 단어가 본문에 있지 않은가
- [ ] 이름과 상품명이 **이 주문의 것**이 맞나
- [ ] `{구매자}` 처럼 **안 채워진 칸**이 남아 있지 않나

## 발송하기 전에 (--send 쓸 때만)

- [ ] 받는 주소가 **내 주소** 하나인가
- [ ] 실제 고객 주소가 한 개도 없는가
- [ ] 제목에 `[테스트]` 가 붙어 있나

## 하나라도 걸리면

지시문을 길게 고치지 마세요. **규칙에 한 줄**을 더합니다.

`02_규칙/안내규칙.csv` 를 열고
- 넣으면 안 되는 말이면 → `넣으면안되는말` 칸에 `|` 로 이어서 추가
- 문장 자체가 틀렸으면 → `안내문장틀` 칸을 고침

고치고 다시 돌리면 검수가 통과합니다.
