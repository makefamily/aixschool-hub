# 카페 바이럴 마케터 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 게시판마다 하루에 올리는 글 수를 지켰나 | 하루에 몰아 올리면 도배로 걸립니다 | `발행규칙.csv` 의 하루 최대를 확인합니다 |
| 올리는 시간과 글 사이 간격을 지켰나 | 새벽에 올리거나 연달아 올리면 광고처럼 보입니다 | `발행규칙.csv` 의 시각·간격을 확인합니다 |
| 광고로 신고당하기 쉬운 말이 없나 | 최저가·카톡 문의·전화번호는 카페 강퇴 사유입니다 | `금지어.csv` 에 그 말을 한 줄 더합니다 |

**사람 눈으로 한 번 더**

- [ ] 내 카페 규정(하루 글 수, 광고 금지 말)을 읽고 표에 반영했나
- [ ] 예약 시각이 손님이 많이 보는 시간인가
- [ ] 확인 필요가 0개인가
