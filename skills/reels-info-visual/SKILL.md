# 정보 시각화형 릴스 편집 (에세이·튜토리얼)

완성 목표는 말의 뜻을 실제 시각 자료로 계속 바꿔 보여 주는 토킹헤드다. 줌과 자막 장식으로 화면 변화를 채우지 않는다. 참고한 것은 특정 크리에이터의 영상 문법이며, 그 영상을 그대로 따라 만들거나 그 사람의 얼굴·이름·소재를 가져다 쓰지 않는다.

## 준비
- 촬영본(mp4), 받아쓴 자막(없으면 만든다). 공통 준비와 설치는 `reels-style-router/SKILL.md`의 "공통 준비"를 따른다.
- 시각 자료에 쓸 이미지·화면 녹화·캡처는 학생이 가진 것이나 학생 허락 아래 만든 것만 쓴다. 남의 사진·영상은 출처와 이용 허락을 학생에게 확인한다.

## 모드
- `essay-story`: 경험, 관점, 사례, 비유 중심. 말하는 화면 35~45%, 자료 화면 55~65%. 의미가 바뀌는 간격은 대체로 1.4~1.7초.
- `tutorial`: 도구, 방법, 단계, 기능 설명. 말하는 화면 + 화면 캡처 + 단계 제목을 2~3초 단위로 바꾼다.

## 화면 규칙
- 첫 제목은 세리프 계열의 에디토리얼 헤드라인.
- 자막은 짧게 끊는다. 말을 그대로 되풀이하는 큰 카드로 채우지 않는다.
- 명사·장소·제품·행동이 나오면 실제 이미지, 화면, 도표로 바꾼다. 수치·결과·출처·전후 비교는 풀스크린 증거 화면으로.
- 전환은 하드컷이 기본이다. 정보 변화 없는 임의 줌·팬은 쓰지 않는다.
- 같은 보조 자료를 반복해서 쓰지 않는다.

## 순서
1. 받아쓴 자막 전체를 읽고 뜻 단위로 나눈다.
2. 구간마다 `talking_head`, `broll`, `ui`, `evidence`, `title`, `diagram` 중 하나를 정한다.
3. 구간마다 `start`, `end`, `dialogue`, `scene_type`, `asset_query`, `transition`을 적은 `edit-plan.json`을 만든다(`reels-style-router`의 `router.py --style info-visual`이 초안을 만들어 준다).
4. 대본에 없는 사실을 자료 화면이 새로 주장하지 않게 한다.
5. 렌더 후 화면 변화 빈도, 말하는 화면 비율, 자료 화면 비율, 자막 길이를 점검하고 학생에게 대표 화면을 보여 준다.
