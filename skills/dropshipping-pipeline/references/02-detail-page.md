# 2단계 — 상세페이지 구조 개선

## 입력

- 자사 구조 파일 (예: `product.json` — Shopify Dawn 테마 블록 구조)
- 잘 팔리는 경쟁사 페이지 원문 (제목/가격/평점/후기/FAQ). 없으면 `WebFetch`로 수집

## 제약

- 파일 구조·형식을 그대로 유지한다. 그대로 복붙해서 쓸 수 있어야 한다.
- 효능 단정 표현 금지.
- 첫 화면은 반드시 **고통 → 해결** 순서.

## 절차

1. 경쟁사가 잘 팔리는 이유 3가지 분석 (구조·카피·신뢰요소 관점)
2. 그 요소를 반영한 새 구조 파일 생성
3. `python3 -m json.tool <파일>`로 JSON 유효성 검증
4. 미리보기 HTML 생성 — 변경된 블록을 시각적으로 표시

## 검증된 추가 블록 패턴 (Shopify Dawn 기준)

| 블록 | 위치 | 목적 |
|------|------|------|
| `pain_hook` | title 위 | 고통 후킹 한 줄 |
| `rating` | title 아래 | 별점 |
| `social_proof` | 가격 근처 | 구매자 수·최근 판매량 |
| `risk_reversal` | 구매 버튼 바로 아래 | 환불 보장 |
| `collapsible_tab` × N | 하단 | 사용 루틴 / 변화 타임라인 / 후기 / FAQ |

주의: `rating`, `collapsible_tab` 블록 타입은 Dawn 테마 기준. 다른 테마면 지원 여부를 먼저 확인한다.

## 산출

1. 경쟁사 성공요인 3가지
2. 변경 사항 + 이유 표 (변경 전 / 변경 후 / 왜)
3. 새 구조 파일 전문 → `claudedocs/<상품슬러그>/02-detail-structure.json`
4. 미리보기 → `claudedocs/<상품슬러그>/02-preview.html`

미검증 사항(테마 호환성 등)은 표 아래 별도 명시.
