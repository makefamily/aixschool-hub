# 드랍쉬핑 파이프라인

상품 발굴 → 상세페이지 구조 개선 → 광고 이미지·카피 생성. 각 단계는 독립 실행 가능하며, 단계 사이에는 항상 사용자 승인 게이트를 둔다.

## 공통 하드룰

- 모든 수치(매입가·판매가·마진율·판매량)는 실측 근거가 없으면 반드시 `(추정)`을 붙인다. 추측을 사실처럼 쓰지 않는다.
- 광고 심의 리스크는 상품 선정과 카피 작성 **양쪽 모두**에서 1차 필터로 적용한다. 효능 단정, 의학적 표현, 과장 수치, 비포/애프터 조작 암시 금지.
- 유료 생성(Higgsfield 등)은 예상 크레딧 산정 → 잔여 크레딧 보고 → 명시 승인 → 실행 순서를 예외 없이 지킨다.
- 산출물은 MD/JSON 등 원래 형식으로 저장하고, 답변에는 `file://` 절대경로 클릭 링크를 제공한다.
- 이모지 금지. "마법" 표현 금지.

## 게이트 프로토콜

각 단계 종료 시:
1. 산출물 목록 + 한 줄 요약 제시
2. 미검증 항목·리스크를 별도 표기
3. 사용자 승인 대기 (자동으로 다음 단계 진행 금지)
