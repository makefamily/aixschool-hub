# 카드뉴스 기본 틀

이 규칙은 "기본 틀"이다. 색과 글꼴은 학생 브랜드로 바꿔도 된다. 구조 규칙은 지킨다.

## 구조 (바꾸지 않는다)
- 비율 4:5 세로, 1080x1350.
- 한 장에 메시지 하나. 글자는 적게, 여백은 넉넉하게.
- 큰 제목은 두 줄로 끊고 화면을 압도할 만큼 크게. 본문은 작게. 제목과 본문 크기 차이가 클수록 읽기 쉽다.
- 강조색은 하나만, 한 장에서 핵심 단어 한 곳(또는 도식 한 곳)에만.
- 굵고 각진 고딕 한 종류. 굵기 변화는 2~3개까지.
- 사람 얼굴, 로고, 상표, 실제 서비스 화면을 그리지 않는다. 단순한 도식과 아이콘만.
- 글자는 화면 글자로 얹는다. AI 그림이 한국어 글자를 직접 쓰게 하지 않는다.

## 기본 색 (예시 값, 학생 브랜드로 교체 가능)
| 자리 | 기본 값 | brand.json 키 |
|---|---|---|
| 배경 | 따뜻한 아이보리 #F7F4EC | bg |
| 글자 | 짙은 잉크 #131313 | ink |
| 어두운 패널 | 짙은 잉크 #131313 | panel |
| 패널 위 글자 | 아이보리 #F7F4EC | onpanel |
| 강조 | 진한 파랑 #2457D6 | accent |
| 글꼴 | Pretendard (없으면 시스템 고딕) | font |

학생 브랜드 색으로 바꿀 때: 배경과 글자의 밝기 차이가 크게 나야 한다(밝은 배경이면 어두운 글자). 강조색이 어두운 패널 위에서 안 보이면 스크립트가 밝게 섞어 쓴다. 강조색이 너무 옅으면 사진처럼 번져 보이니 진한 색을 고른다.

## 장 역할 (5장 기본)
1. 표지 훅: 읽는 사람이 "내 얘기다" 하게 하는 한 문장. 도식 하나.
2. 문제: 독자가 겪는 장면 하나.
3. 방법: 번호 3~4개 이하. 한 줄에 한 동작.
4. 결과: 전/후 두 칸 또는 한 문장 결과.
5. 요약과 다음 행동: 지금 2분 안에 할 수 있는 행동 하나.

## 글자 길이 감각
- 제목 한 줄 12자 안팎(공백 포함), 두 줄.
- 본문 한 덩어리 3줄 안쪽. 넘치면 스크립트가 글자를 줄이다가 FAIL로 알려 준다. 그때는 글을 줄인다.
- 조사만 다음 줄에 남기지 않는다. 의미 단위로 끊는다.

## 카드 종류와 cards.json 칸
- cover: tag, title, sub, motif(stack|check|arrow), image
- point: tag, title, body, dark, image
- steps: tag, title, items[{head, text}] (3~4개)
- compare: tag, title, left{label, items[]}, right{label, items[]}
- closing: tag, title, body, action
- 모든 칸에서 `*강조*`, `**굵게**`, 줄바꿈 `\n`을 쓸 수 있다.
