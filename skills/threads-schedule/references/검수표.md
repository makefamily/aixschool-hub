# SNS 마케터 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 한 칸이 500자를 넘지 않나 | 스레드는 한 칸에 500자까지만 들어갑니다 | 프로그램이 이어쓰기로 나눕니다. 걸리면 AI가 원인을 확인합니다 |
| 정해둔 시간에 한 개씩만 올라가나 | 한꺼번에 올리면 앞의 글이 묻힙니다 | `발행시간.csv` 를 확인합니다 |
| 본문에 링크를 넣지 않았나 | 링크가 있으면 덜 퍼집니다. 링크는 첫 댓글에 | 원고에서 링크를 빼고 댓글로 옮깁니다 |

**사람 눈으로 한 번 더**

- [ ] 첫 줄만 읽어도 더 읽고 싶어지나
- [ ] 내 말투와 맞나
- [ ] 확인 필요가 0개인가
