# 영상편집자 검수표

스크립트를 실행하면 아래 세 가지를 프로그램이 먼저 봅니다. 결과 화면 맨 위에 **통과 / 확인 필요**로 나옵니다.

| 확인할 것 | 왜 | 걸리면 |
|---|---|---|
| 자막 시간이 겹치지 않나 | 겹치면 자막 두 줄이 한꺼번에 뜹니다 | 원래 자막 파일의 시간을 확인합니다. 걸리면 AI가 원인을 확인합니다 |
| 잘린 곳마다 이유가 있나 | 이유 없이 잘린 곳이 있으면 중요한 말이 날아갔을 수 있습니다 | `빼는말.csv` 와 `자르기기준.csv` 를 확인합니다 |
| 너무 많이 자르지 않았나 | 너무 바짝 자르면 말이 숨 가쁘게 들립니다 | `자르기기준.csv` 의 쉬는 시간을 늘리거나 빼는 말을 줄입니다 |

**사람 눈으로 한 번 더**

- [ ] 잘린 자리에서 말이 뚝 끊기지 않나 (영상으로 한 번 보기)
- [ ] 꼭 남겨야 할 말이 빠지지 않았나
- [ ] 확인 필요가 0개인가
