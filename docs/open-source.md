# 대표가 실제로 써 본 오픈소스

대표가 직접 써 보거나 설치해 본 것들만 모았어요. 깔고 쓰는 건 허브의 AI에게 말하면 확인한 뒤에 해 줘요.
라이선스 주의: 무료여도 조건이 있는 것(Remotion, Basic Memory)과 라이선스가 없는 것(naver-bc-automation)은 표시해 두었어요.

오픈소스는 누구나 보고 쓰라고 공개된 프로그램이에요. 정보는 2026-11-18에 각 공식 저장소에서 확인했어요. 쓰기 전에 항목의 주의를 먼저 읽으세요.

## 영상

### Remotion

- 무엇을 해 줘요: 코드로 영상을 만들어 주는 도구예요. 글과 숫자만 바꿔서 같은 모양의 영상을 여러 개 찍어낼 수 있어요.
- 이럴 때: 서비스 소개·설명 영상을 같은 틀로 계속 만들 때
- 링크: https://github.com/remotion-dev/remotion
- 라이선스: Remotion 자체 라이선스
- 주의: 개인, 직원 3명 이하 영리 회사, 비영리는 무료예요. 직원이 4명 이상인 영리 회사는 회사 라이선스(유료)가 필요해요. 쓰기 전에 우리 회사 규모부터 확인하세요.
- 허브에서 AI에게 이렇게 말해 보세요: "Remotion으로 내 서비스 소개 영상 30초짜리 만들어 줘. 필요하면 깔아 줘"

### HyperFrames

- 무엇을 해 줘요: 웹페이지를 그대로 영상으로 뽑아 줘요. 글자가 움직이는 영상, 화면 전환 영상에 잘 맞아요.
- 이럴 때: 글 하나를 짧은 소개 영상이나 쇼츠로 만들 때
- 링크: https://github.com/heygen-com/hyperframes
- 라이선스: Apache-2.0 (자유롭게 사용, 상업 사용 가능)
- 주의: 영상으로 뽑을 때 컴퓨터가 꽤 일해서 시간이 걸려요. 처음에는 짧은 길이로 시험해 보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "HyperFrames로 이 글을 15초 세로 영상으로 만들어 줘. 필요하면 깔아 줘"

### FFmpeg

- 무엇을 해 줘요: 영상과 소리를 자르고, 붙이고, 크기를 바꿔 주는 기본 도구예요. 다른 영상 도구들도 속에서 이걸 써요.
- 이럴 때: 영상 앞뒤를 자르거나, 세로 영상으로 바꾸거나, 소리만 뽑을 때
- 링크: https://ffmpeg.org/
- 라이선스: LGPL 2.1 이상 (일부 옵션은 GPL)
- 주의: 내가 쓰는 건 문제없어요. 내가 만든 프로그램에 넣어서 남에게 나눠 줄 때는 조건이 있으니 먼저 물어보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 영상 앞뒤 3초를 잘라서 인스타 세로 크기로 바꿔 줘. 필요하면 깔아 줘"

### Whisper

- 무엇을 해 줘요: 말소리를 글로 받아 적어 줘요. 맥에서 빠른 whisper.cpp와 애플 칩용 mlx-whisper가 있어요.
- 이럴 때: 강의·인터뷰·회의 녹음을 글로 옮기거나 영상 자막을 만들 때
- 링크: https://github.com/ggml-org/whisper.cpp
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 내 컴퓨터에서만 돌아가서 녹음이 밖으로 나가지 않아요. 처음에 큰 파일을 한 번 받아야 하고, 사람 이름과 고유명사는 자주 틀려서 꼭 확인해야 해요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 녹음 파일을 Whisper로 글로 옮겨 줘. 이름은 틀릴 수 있으니 표시해 줘"

## 글·문서

### kordoc

- 무엇을 해 줘요: 한글(HWP) 공문서를 읽어서 글로 바꿔 주고, 신청서 빈칸을 채워 줘요. 한컴오피스가 없어도 돼요.
- 이럴 때: 지원사업 공고문을 읽거나 신청서 양식을 채울 때
- 링크: https://github.com/chrisryugj/kordoc
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 주민번호·연락처가 든 서류는 내 컴퓨터에서만 다루세요. 제출 전에 사람이 한 번 꼭 읽어 보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 공고문 한글 파일을 kordoc으로 읽고 신청 조건만 정리해 줘. 필요하면 깔아 줘"

### python-hwpx

- 무엇을 해 줘요: 한글 문서(HWPX)의 칸 하나하나를 정확하게 고쳐 줘요. 한컴오피스가 없어도 돼요.
- 이럴 때: 표 안의 칸만 바꾸거나, 같은 양식을 여러 번 채울 때
- 링크: https://github.com/airmang/python-hwpx
- 라이선스: Apache-2.0 (자유롭게 사용, 상업 사용 가능)
- 주의: HWPX 형식이 대상이에요. 옛 형식(HWP)은 먼저 HWPX로 저장해야 해요. 채운 뒤 쪽 수가 늘지 않았는지 확인하세요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 신청서 HWPX의 빈칸을 내 사업 정보로 채워 줘. 쪽 수가 늘지 않게 확인해 줘"

### im-not-ai

- 무엇을 해 줘요: AI가 쓴 티가 나는 한국어 글을 사람이 쓴 것처럼 다듬어 줘요.
- 이럴 때: 블로그·스레드·전자책 글에서 번역투와 AI 말투를 걷어낼 때
- 링크: https://github.com/epoko77-ai/im-not-ai
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 내용은 그대로 두고 말투만 고쳐야 해요. 다듬은 뒤 원문과 비교해서 숫자와 고유명사가 바뀌지 않았는지 보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "im-not-ai 방식으로 이 글의 AI 티를 고쳐 줘. 내용과 숫자는 바꾸지 마"

### k-skill

- 무엇을 해 줘요: 한국 생활에 맞춘 AI 스킬 모음이에요. 글자 수 세기, 한국어 말투 다듬기 같은 것이 들어 있어요.
- 이럴 때: 글자 수 제한이 있는 글을 쓰거나, 한국 서비스에 맞는 작업을 AI에게 시킬 때
- 링크: https://github.com/NomaDamas/k-skill
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 모음집이라 전부 깔지 말고 필요한 것만 고르세요. 스킬마다 로그인이나 외부 서비스가 필요할 수 있으니 AI에게 조건부터 물어보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "k-skill에서 내 글쓰기에 도움이 될 스킬만 골라서 알려 줘. 깔기 전에 조건부터 말해 줘"

### Typst

- 무엇을 해 줘요: 책이나 보고서를 깔끔한 PDF로 조판해 줘요. 워드보다 쪽 나눔과 표가 안정적이에요.
- 이럴 때: 전자책·제안서·가이드북을 PDF로 만들 때
- 링크: https://github.com/typst/typst
- 라이선스: Apache-2.0 (자유롭게 사용, 상업 사용 가능)
- 주의: 한글 글꼴이 내 컴퓨터에 있어야 예쁘게 나와요. 만든 PDF는 한 쪽씩 열어서 글자 잘림을 확인하세요.
- 허브에서 AI에게 이렇게 말해 보세요: "Typst로 이 원고를 A5 전자책 PDF로 만들어 줘. 필요하면 깔아 줘"

### bookforge

- 무엇을 해 줘요: 주제 한 줄로 전자책 PDF를 만들어 줘요. 스타일 6가지와 쪽 배치 검사 규칙이 들어 있어요.
- 이럴 때: 내 노하우를 전자책으로 묶어서 자료로 줄 때
- 링크: https://github.com/gongnyang/bookforge
- 라이선스: MIT (함께 든 글꼴은 OFL 1.1)
- 주의: 마지막 업데이트가 2026년 9월 초예요. 내용은 사람이 직접 읽고 사실 확인을 해야 해요.
- 허브에서 AI에게 이렇게 말해 보세요: "bookforge로 내 서비스 안내 전자책 20쪽을 만들어 줘. 목차부터 먼저 보여 줘"

## 디자인·카드뉴스

### Pretendard

- 무엇을 해 줘요: 읽기 편한 한글 글꼴이에요. 덱, 카드뉴스, 영상 자막에 쓰기 좋아요.
- 이럴 때: 화면과 인쇄물의 글꼴을 하나로 통일할 때
- 링크: https://github.com/orioncactus/pretendard
- 라이선스: OFL 1.1 (상업 사용 가능)
- 주의: 글꼴을 그대로 팔거나 이름만 바꿔 다시 배포하는 것은 안 돼요. 문서에 쓰는 것은 자유예요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 카드뉴스 글꼴을 Pretendard로 통일해 줘. 필요하면 깔아 줘"

### gongnyang-prompt-kit

- 무엇을 해 줘요: 이미지 만드는 AI에게 줄 그림 설명문을 잘 써 줘요. 막연한 부탁을 정확한 설명문으로 바꿔 줘요.
- 이럴 때: 카드뉴스 그림, 상품 사진 느낌의 이미지를 만들 때
- 링크: https://github.com/gongnyang/gongnyang-prompt-kit
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 그림을 실제로 만드는 건 내 ChatGPT 같은 계정이에요. 한도가 다 차면 막히니 한 번에 많이 시키지 마세요.
- 허브에서 AI에게 이렇게 말해 보세요: "이 카드뉴스 3번째 장 그림 설명문을 gongnyang-prompt-kit 방식으로 써 줘"

### deck-factory

- 무엇을 해 줘요: 한 줄 의도로 발표 자료(덱)를 어두운 잡지 느낌의 웹페이지로 만들어 줘요.
- 이럴 때: 강의·설명회 발표 자료의 첫 판을 빨리 볼 때
- 링크: https://github.com/gongnyang/deck-factory
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 마지막 업데이트가 2026년 7월이에요. 허브에 덱 만들기 직원이 이미 있으니, 다른 분위기를 원할 때만 써 보세요.
- 허브에서 AI에게 이렇게 말해 보세요: "deck-factory 방식으로 내 서비스 소개 덱 10장을 만들어 줘. 먼저 구조부터 보여 줘"

## 자료 조사

### insane-search

- 무엇을 해 줘요: 막혀서 안 열리는 사이트도 AI가 끝까지 읽어 오게 해 줘요.
- 이럴 때: 웹 검색으로는 안 읽히는 글을 조사해야 할 때
- 링크: https://github.com/fivetaku/insane-search
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 사이트의 접근 제한을 돌아가는 방식이라 그 사이트의 이용 약관을 먼저 확인하세요. 로그인해야 보이는 글이나 개인정보는 대상이 아니고, 읽어 온 글을 그대로 다시 올리면 안 돼요.
- 허브에서 AI에게 이렇게 말해 보세요: "insane-search로 이 링크 내용을 읽어서 핵심만 정리해 줘. 약관 문제가 있는지도 알려 줘"

### yt-dlp

- 무엇을 해 줘요: 유튜브 같은 영상의 정보, 자막, 음성을 받아 줘요.
- 이럴 때: 경쟁 채널 영상의 자막을 모아 분석하거나, 내 영상 소리를 뽑을 때
- 링크: https://github.com/yt-dlp/yt-dlp
- 라이선스: Unlicense (제한 없음)
- 주의: 프로그램은 자유지만 남의 영상은 저작권이 있어요. 분석·공부용으로만 쓰고 그대로 다시 올리지 마세요.
- 허브에서 AI에게 이렇게 말해 보세요: "yt-dlp로 이 유튜브 영상의 자막만 받아서 핵심을 정리해 줘. 영상 자체는 저장하지 마"

### Agent-Reach

- 무엇을 해 줘요: 트위터(X), 유튜브, 레딧 등 여러 사이트의 글·댓글·자막을 AI가 읽어 오게 해 줘요. 읽기만 하고 글쓰기는 하지 않아요.
- 이럴 때: 여러 사이트에서 사람들 반응을 모아 볼 때
- 링크: https://github.com/Panniantong/Agent-Reach
- 라이선스: MIT (자유롭게 사용, 상업 사용 가능)
- 주의: 설명서가 중국어예요. 일부 사이트는 로그인이 필요한데, 비밀번호는 AI에게 알려 주지 말고 직접 로그인하세요. 대표는 설치까지 확인했고 실제 사용 횟수는 적어요.
- 허브에서 AI에게 이렇게 말해 보세요: "Agent-Reach로 이 주제에 대한 사람들 반응을 읽어 와서 정리해 줘. 로그인이 필요하면 먼저 알려 줘"

## 자동화·브라우저

### Playwright

- 무엇을 해 줘요: AI가 브라우저를 사람처럼 열고, 누르고, 화면을 캡처해 줘요.
- 이럴 때: 내가 만든 웹페이지가 폰·PC 폭에서 잘 보이는지, 버튼이 되는지 점검할 때
- 링크: https://github.com/microsoft/playwright
- 라이선스: Apache-2.0 (자유롭게 사용, 상업 사용 가능)
- 주의: 내가 만든 페이지 점검에 쓰세요. 로그인·결제가 걸린 남의 사이트를 자동으로 누르게 하면 약관 위반이 될 수 있어요.
- 허브에서 AI에게 이렇게 말해 보세요: "Playwright로 내가 만든 페이지를 폰 폭과 PC 폭으로 열어서 버튼이 다 되는지 확인해 줘"

### agent-browser

- 무엇을 해 줘요: AI가 쓰기 쉽게 만든 가벼운 브라우저 조작 도구예요. 페이지를 열고 눈으로 확인하는 점검에 좋아요.
- 이럴 때: 만든 덱이나 페이지를 실제로 넘겨 보며 확인할 때
- 링크: https://github.com/vercel-labs/agent-browser
- 라이선스: Apache-2.0 (자유롭게 사용, 상업 사용 가능)
- 주의: Playwright와 하는 일이 비슷해요. 둘 중 하나만 있으면 돼요.
- 허브에서 AI에게 이렇게 말해 보세요: "agent-browser로 이 덱을 처음부터 끝까지 넘겨 보고 글자가 잘리는 장이 있는지 알려 줘"

### naver-bc-automation

- 무엇을 해 줘요: 네이버 브랜드커넥트 상품 리뷰를 블로그 글로 만드는 흐름을 보여 주는 예시 저장소예요.
- 이럴 때: 블로그 글을 쓰는 AI 직원의 작업 순서를 짤 때 참고
- 링크: https://github.com/Daewooki/naver-bc-automation
- 라이선스: 라이선스 없음 (코드를 가져다 쓸 수 없어요)
- 주의: 참고만 하세요. 라이선스가 없어서 코드 복사와 재배포는 안 돼요. 네이버 자동 로그인, 봇 감지 우회, 자동 발행은 네이버 약관상 위험해서 쓰지 않아요.
